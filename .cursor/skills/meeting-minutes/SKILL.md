# 整理会议纪要

## 你需要提供

- **录音文本**（必须）：本次会议的录音转写全文
- **会议类型**（如未说明则询问）：
  - 管理层双周会
  - 国际业务部双周会
  - 专项会议（说明主题）

## 我会自动做的

### 1. 学习语言风格

读取同类型最近 3-5 期历史纪要，学习：
- 用语习惯（如"经讨论决定""会议要求"等）
- 议题组织方式
- 决议和待办的表述格式
- 详略程度

历史纪要位置：
- 管理层双周会 → docs/meetings/management-biweekly/
- 国际业务部双周会 → docs/meetings/intl-biz-biweekly/
- 专项会议 → docs/meetings/special/

如目录中尚无历史纪要，则使用 templates/meetings/ 中对应模板，并告知用户上传历史纪要以改善风格。

### 2. 提取会议内容

从录音文本中提取：
- 会议基本信息（时间、参会人等，如文本中有）
- 各议题讨论内容
- 决议事项
- 待办事项（责任人、时间）
- 需上报/决策事项

### 3. 生成纪要

- 按对应模板结构输出
- **语言风格对齐历史纪要**，不另起一套写法
- 录音文本中未提及的信息不编造，缺失项标注"[待补充]"

### 4. 关联更新

- 待办追加到 docs/meetings/action-items.md（标注会议来源和类型）
- 专项会议 → 更新对应 docs/projects/{专项}/会议纪要索引.md
- 管理层双周会 → 标注本期经营汇报路径（如有）

### 5. 质量自检

对照 references/纪要质量检查清单.md 逐项检查。

### 6. 输出给你确认

先输出完整纪要正文，你确认后再保存到对应目录。

## 保存路径

| 会议类型 | 路径 |
|----------|------|
| 管理层双周会 | docs/meetings/management-biweekly/YYYY/YYYY-MM-DD-第N期.md |
| 国际业务部双周会 | docs/meetings/intl-biz-biweekly/YYYY/YYYY-MM-DD-第N期.md |
| 专项会议 | docs/meetings/special/YYYY/YYYY-MM-DD-会议主题.md |

## 使用示例

你：这是今天管理层双周会的录音文本：[粘贴文本]

我：
1. 读取最近几期管理层双周会纪要学习风格
2. 生成纪要
3. 请你确认

你：可以，第3条待办责任人改成李四

我：修改后保存到 docs/meetings/management-biweekly/2026/2026-07-01-第12期.md
