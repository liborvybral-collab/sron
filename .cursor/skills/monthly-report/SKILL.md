# 编写部门月报

## 你需要提供

- **经营数据**（必须），可以是：
  - Excel/表格数据（粘贴或 @文件）
  - 部门提交的原始数据草稿
  - 关键指标数字 + 说明
- **目标部门和月份**（如未说明则询问）：
  - 国际业务部
  - 工程部
  - 计划运营部

## 我会自动做的

### 1. 确认部门

| 部门 | 识别关键词 | 模板 | 保存目录 |
|------|-----------|------|----------|
| 国际业务部 | 国际、海外、外贸 | templates/reports/国际业务部月报模板.md | docs/reports/monthly/intl-biz/ |
| 工程部 | 工程、项目、施工 | templates/reports/工程部月报模板.md | docs/reports/monthly/engineering/ |
| 计划运营部 | 计划、运营、综合 | templates/reports/计划运营部月报模板.md | docs/reports/monthly/planning-ops/ |

### 2. 读取参照

- 对应部门月报模板
- 该部门上月月报（学习分析思路和表述方式）
- 该部门去年同期月报（用于同比）
- 指标口径 → docs/reference/核心经营指标口径.md
- 原始数据 → data/{部门}/YYYY-MM/（国际业务部见 data/intl-biz/README.md 工作表对照）

### 3. 数据分析

基于你提供的数据：
- 计算同比、环比
- 识别异常波动（变动超过 10% 的指标）
- 分析结构（各分项占比、贡献度）
- 数据有矛盾或缺失时，列出问题请你确认，不编造

按 references/月报数据核对清单.md 进行核对。

### 4. 按模板撰写

严格按部门模板结构输出。

#### 国际业务部月报重点

- 海外订单签约/回款
- 在执行项目进展
- 市场开拓（新市场/新客户）
- 汇率与贸易风险

#### 工程部月报重点

- 在建项目清单与进度
- 质量/安全/环保
- 成本执行与偏差
- 人员与设备资源

#### 计划运营部月报重点

- 公司整体经营指标汇总
- 各部门计划执行情况
- 运营效率分析
- 跨部门协调事项

### 5. 输出给你确认

先输出完整月报，你确认后再保存。

## 保存路径

`docs/reports/monthly/{部门}/YYYY-MM-{部门名}月报.md`

## 使用示例

你：这是国际业务部6月的数据：[粘贴表格]，帮我写月报

我：
1. 读取国际业务部月报模板和5月月报
2. 分析数据（同比环比、异常项）
3. 生成月报
4. 请你确认

你：第三节回款分析再补充一下中东项目的情况

我：补充后保存到 docs/reports/monthly/intl-biz/2026-06-国际业务部月报.md
