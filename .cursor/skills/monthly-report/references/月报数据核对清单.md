# 月报数据核对清单

## 核心指标

- [ ] 营业收入（本月 / 同比 / 环比）
- [ ] 营业成本（如适用）
- [ ] 毛利率（如适用）
- [ ] 净利润（如适用）
- [ ] 净利率（如适用）

## 部门特有指标

### 国际业务部

- [ ] 新签订单
- [ ] 回款额 / 回款率
- [ ] 在执行项目进度

### 工程部

- [ ] 在建项目数
- [ ] 完成产值
- [ ] 质量安全指标

### 计划运营部

- [ ] 全公司收入/利润汇总
- [ ] 各部门计划执行率
- [ ] 运营效率指标

## 计算校验

- [ ] 同比 = (本期 - 去年同期) / 去年同期 × 100%
- [ ] 环比 = (本期 - 上期) / 上期 × 100%
- [ ] 各分项加总 = 合计数

## 异常标记

- [ ] 变动超过 ±10% 的指标已附原因分析
- [ ] 新增/消失的业务线已说明
- [ ] 数据缺失项已列出，未编造
