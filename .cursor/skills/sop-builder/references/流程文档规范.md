# 流程文档（SOP）编写规范

## 必备章节

1. **目的** — 为什么要有这个流程
2. **适用范围** — 哪些部门/场景适用
3. **术语定义** — 关键术语解释
4. **角色与职责** — 各岗位做什么
5. **流程图** — Mermaid 格式
6. **详细步骤** — 逐步说明
7. **相关文件** — 模板、表单索引
8. **修订记录** — 版本历史

## 流程图要求

使用 Mermaid `flowchart TD` 格式，示例：

```mermaid
flowchart TD
    A[开始] --> B[步骤1]
    B --> C{判断}
    C -->|是| D[步骤2]
    C -->|否| E[异常处理]
    D --> F[结束]
```

```yaml
type: sop
status: draft
version: 1.0
---
```
