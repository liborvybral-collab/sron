- 流程名称（如：月报编制流程、会议纪要整理流程）
- 流程目的
- 现有做法描述（如有）
- 需参考的已有流程（如有）

## 我会自动做的

### 1. 读取参照

- 规范：references/流程文档规范.md
- 已有流程：docs/sops/ 目录
- 相关模板：templates/

### 2. 梳理流程

与用户确认（或基于描述推断）：
- 流程触发条件
- 参与角色/岗位
- 各步骤及先后顺序
- 输入物 / 输出物
- 审批节点（如有）
- 时效要求
- 异常处理

### 3. 撰写 SOP

按 references/流程文档规范.md 输出，包含：
- 目的与适用范围
- 术语定义
- 角色与职责
- 流程图（Mermaid 格式）
- 详细步骤说明
- 相关表单/模板索引
- 修订记录

### 4. 输出

保存路径：docs/sops/流程名称.md

先输出给用户确认，确认后保存。

## 使用示例

你：帮我搭建部门月报编制流程，每月 25 号各部门提交数据，计运部 28 号汇总出月报

我：
1. 读取已有 SOP 和月报模板
2. 梳理流程步骤和角色
3. 生成 SOP 含 Mermaid 流程图
4. 请你确认
