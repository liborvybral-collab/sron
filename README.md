# sron

河南实荣公司的经营分析知识库，用于 Cursor AI 辅助日常经营分析工作。

## 主要功能

| 工作 | 使用方式 | 说明 |
|------|----------|------|
| 整理会议纪要 | `/meeting-minutes` + 粘贴录音文本 | 参照历史纪要风格生成 |
| 编写部门月报 | `/monthly-report` + 提供数据 | 按模板分析数据撰写 |
| 编写经营汇报 | `/business-briefing` | 生成 PPT 大纲及演讲备注 |
| 专项工作跟踪 | `/project-tracker` | 进展更新、汇报撰写 |
| 搭建流程 | `/sop-builder` | 标准化流程文档 |

## 快速开始

1. 在 Cursor 中打开本仓库
2. 上传 2-3 期历史纪要和各部门 1-2 期历史月报（作为风格参照）
3. 日常使用：把录音文本或数据发给 AI 即可
