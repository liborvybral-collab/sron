# 标准化体系框架

## 体系结构

公司标准化建设当前按「制度 + 流程」双轨推进：

| 层级 | 说明 | 存放目录 |
|------|------|----------|
| 管理制度 | 明确权责、标准与考核兑现规则 | `docs/sops/`（type: policy） |
| 标准化流程（SOP） | 明确触发、步骤、输入输出与时效 | `docs/sops/`（type: sop） |
| 参考资料/已发布制度原稿 | 访谈与定稿参照 | `docs/projects/standardization-system/references/` |
| 项目跟踪 | 里程碑、进展、会议索引 | `docs/projects/standardization-system/` |
