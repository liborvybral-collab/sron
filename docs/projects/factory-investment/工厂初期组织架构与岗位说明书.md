# 实荣工厂初期组织架构与关键岗位说明书

> 适用阶段：一期轻资产示范工厂（粮仓装配仓核心产线）  
> 编制红线：初期 **≤30人**（建议落地 **24–28人**）  
> 使用方式：可直接复制组织图与岗位说明书发钉钉群 / 贴入汇报PPT

---

## 一、设计原则

**集中职能精简机构专责**

---

## 二、在公司架构中的位置

```text
董事长 / 温总
 └── 总经办（统筹）
      ├── 总部职能部门
      │    业务｜技术中心｜成本招采｜计划运营｜工程｜物流｜质监｜财务｜人力｜行政｜研发…
      └── 制造工厂（全资制造主体 / 一期基地）
           └── 厂长（制造总负责人）
                ├── 虚线：工艺 → 技术中心
                ├── 虚线：质量 → 质监部
                ├── 虚线：物料/外协计划 → 成本招采
                └── 虚线：发运 → 物流部
```

业务上接受 **计划运营部节点管控**；行政上可挂「制造中心 / 制造子公司」。

### 3.3 钉钉群可直接复制的精简版

**【实荣工厂初期组织架构】**  
厂长（总责）→ 生产计划 / 质量安全 / 综合后勤（三个接口岗）→ 车间主任 → 下料成型组、装配组、涂装（或外协监造）、仓储发运组；另设工厂工艺专员（挂技术中心）。  
原则：总部管人财物技，工厂只做执行；初期≤30人；一期只保粮仓装配仓核心件。

## 四、关键岗位说明书（一页纸）

### 4.1 厂长（制造总负责人）

| 项目 | 内容 |
|------|------|
| **岗位名称** | 厂长（制造总负责人） |
| **编制** | 1人 |
| **汇报对象** | 总经办 / 公司分管领导；业务节点接受计划运营部管控 |
| **岗位使命** | 把工厂建成“可参观、可控质量、可保交期、可算清成本”的制造执行单元，支撑客户信任与核心产品自制。 |
| **核心职责** | 1. 对产量、交期、质量、成本、安全环保负总责<br>2. 落实主生产计划，确保齐套与节点达成<br>3. 主导客户/外宾参观动线与现场呈现<br>4. 外协边界管控：非标/电控外协，核心件（壁板/立柱/仓顶）自制不失守<br>5. 带队伍：车间主任及班组能力建设；编制严控≤30人<br>6. 推动ERP落地与成本数据真实可追溯<br>7. 周协同、月经营数据向管理层汇报 |
| **关键权限** | 厂内排产与人员调配；日常物资领用审批；质量停线权；安全一票否决现场执行权 |
| **任职要求** | 10年左右车间/工厂管理经验优先；懂钢构或板金成型；能抓交期与现场；不可仅由行政/采购兼管 |
| **考核导向** | 节点达成率、一次交验合格率、单位成本、安全事故、客户参观满意度、编制与费用可控 |
| **激励建议** | 岗位股份 / 入股绑定（按公司方案） |

---

### 4.2 车间主任

| 项目 | 内容 |
|------|------|
| **岗位名称** | 车间主任 |
| **编制** | 1人 |
| **汇报对象** | 厂长 |
| **岗位使命** | 作为现场生产第一责任人，将厂级计划转化为工序执行，对班产、工艺纪律、设备状态与现场秩序负责。 |
| **核心职责** | 组织现场生产与班组执行，管好人、管好设备，落实工艺与质量要求，对班产达成和现场秩序负责，并向厂长日清反馈。 |
| **关键权限** | 班组内岗位调配；现场违纪纠正；提出停机检修建议；下达返工指令 |
| **任职要求** | 熟悉板金下料、折弯及装配现场；具备带班管理经验；执行力强；初期不设生产经理，由本岗位承接现场指挥 |
| **考核导向** | 班产达成率、返工率、设备故障停机时间、安全违章、6S达标 |

---

### 4.3 生产计划岗（兼ERP / 物控）

| 项目 | 内容 |
|------|------|
| **岗位名称** | 生产计划（兼ERP / 物控 / 齐套） |
| **编制** | 1人 |
| **汇报对象** | 厂长（实线）；计划运营部、成本招采部（虚线协同） |
| **岗位使命** | 让工厂“有料可干、有序可排、有数可查”，对齐公司全景计划节点。 |
| **核心职责** | 1. 编制厂级主生产计划与周/日计划，咬合项目发货节点<br>2. 物料齐套、缺料预警，对接成本招采与外协进度<br>3. ERP库存、工单、出入库、批次数据维护<br>4. 产能负荷目视化（瓶颈工序预警）<br>5. 成品集配清单协同仓储发运与物流部<br>6. 为月经营会提供产量、在制、库存、外协占比数据 |
| **关键权限** | 计划下达与调整建议；缺料升级；库存差异核查发起 |
| **任职要求** | 懂生产计划或仓储物控；会用ERP；细致、跟催能力强 |
| **考核导向** | 计划达成率、齐套率、ERP数据准确率、因缺料停线次数 |

---

### 4.4 质量安全岗（兼EHS）

| 项目 | 内容 |
|------|------|
| **岗位名称** | 质量安全（兼EHS / 追溯） |
| **编制** | 1–2人 |
| **汇报对象** | 厂长（实线）；质监部（虚线标准与飞检） |
| **岗位使命** | 让质量“看得见、可追溯、可停线”，安全环保不踩红线；支撑客户参观时的信任呈现。 |
| **核心职责** | 1. 来料检验、过程检验、出厂检验与放行<br>2. 不合格品隔离、返工验证、质量追溯（炉批/工单/项目号）<br>3. 落实公司质检标准；配合质监部抽检/飞检<br>4. 现场安全、消防、职业健康与环保（环评相关现场合规）日常管理<br>5. 质量看板、安全看板维护（参观动线关键内容）<br>6. 重大质量/安全问题双线升级厂长与质监部/总经办 |
| **关键权限** | 质量放行与拒收；质量停线建议/执行；安全隐患停工建议 |
| **任职要求** | 熟悉钢构/板金检验；原则性强；懂基本安全环保要求 |
| **考核导向** | 一次交验合格率、出厂质量事故、追溯完整率、安全隐患闭环、停线有效性 |

## 五、协同机制（建议同步明确）

| 机制 | 频次 | 参与 | 输出 |
|------|------|------|------|
| 厂长日清 | 每日 | 厂长、车间主任、计划、质检 | 产量/齐套/质量/安全钉钉日更 |
| 周协同会 | 每周 | 厂长 + 计划运营 + 成本招采 + 技术工艺 + 质监 | 节点、缺料、工艺、质量闭环 |
| 月经营会 | 每月 | 厂长向管理层汇报 | 产量、单位成本、外协占比、稼动、参观转化 |
| 质量升级 | 即时 | 质检 + 厂长 + 质监部 | 重大质量/安全双线升级总经办 |

## 六、与常规钢构厂的差异（对外解释口径）

| 维度 | 常规钢构厂 | 实荣一期工厂 |
|------|------------|--------------|
| 组织厚度 | 厂内采供销人财齐全 | 总部职能下沉接口，现场极瘦 |
| 产品范围 | 通用钢构广接 | 只做粮仓装配仓核心件 |
| 技术 | 厂内技术科 | 工艺专员挂技术中心，专利/图纸总部闭环 |
| 质量 | 厂内质检科 | 厂内质检 + 质监部标准/飞检 |
| 计划 | 厂内生产科 | 对齐公司全景计划，计划运营盯节点 |
| 客户价值 | 少被参观 | 参观动线是标准能力 |

## 七、下一步建议

2. 先定「涂装自建 / 外协」以锁定最终编制。  
3. 总经办组织一次架构宣贯：总部各部门接口人名单一并公示。  
4. 同步出具《初期组织架构表》正式版，作为0804待办闭环。
