# 实荣工厂一期工种配置建议

## 一、工艺与设备对应关系

| 工艺环节 | 粮仓装配仓 | 非标钢结构 | 主要设备 |
|----------|------------|------------|----------|
| 开平/备料 | 卷板开平、剪板 | 型钢/板材备料 | 开平线、行车 |
| 下料切割 | 壁板、加强件下料 | 板材/型钢切割 | **激光切割机** |
| 冲孔压制 | 壁板螺栓孔、加强筋压型 | 连接板冲孔 | **压力机** |
| 折弯成型 | 壁板折边、立柱/构件折弯 | 箱体、护罩、支架折弯 | **折弯机（建议6米）** |
| 焊接成型 | 立柱、仓顶构架、环梁 | 非标结构件焊接 | **电焊机 / 激光焊（若配置）** |
| 组对装配 | 壁板预装、仓顶组对 | 部件组对、试装 | 工装平台、行车 |
| 打磨矫形 | 焊后打磨、校平校直 | 同上 | 砂轮机、矫平设备 |
| 表面处理 | 喷塑/喷漆（或外协） | 同上 | 喷塑线/喷漆房 |
| 检验包装 | 尺寸孔距、出厂包装 | 同上 | 量具、打包设备 |

## 二、建议工种清单（按工序）

### （一）核心生产工种（建议自有）

| 工种 | 主要工作 | 对应设备/工序 | 粮仓 | 非标 | 初期建议人数 |
|------|----------|---------------|------|------|--------------|
| **激光切割工** | 编程辅助、下料、套料执行 | 激光切割机 | ● | ● | 2–3 |
| **冲压工（压力机操作工）** | 壁板冲孔、压型、模具更换 | 压力机 | ● | ○ | 2–3 |
| **折弯工** | 折弯编程/调机、折边成型 | 折弯机 | ● | ● | 2–3 |
| **电焊工** | 立柱、仓顶、非标结构焊接（二氧化碳/氩弧等） | 电焊机 | ● | ● | 3–5 |
| **装配钳工 / 结构装配工** | 组对、预装、孔位配合、工装使用 | 装配平台 | ● | ● | 3–4 |
| **起重司索工（可兼）** | 行车指挥、吊装转运 | 行车（5–30吨） | ● | ● | 1–2（兼岗） |

### （二）辅助与保障工种

| 工种 | 主要工作 | 说明 | 初期建议 |
|------|----------|------|----------|
| **打磨工 / 抛光工** | 焊渣清理、坡口、外观修整 | 可与焊工/装配兼 | 1–2 或兼岗 |
| **矫形工** | 板件校平、构件校直 | 量小可兼 | 兼岗 |
| **涂装工（喷塑/喷漆）** | 表面处理 | 市场常见外协；自建则单列 | 0–3（或外协监造1人） |
| **质检员** | 孔距、垂直度、焊缝、出厂检验 | 对应质量安全岗 | 1–2 |
| **仓管工** | 原料/成品收发、齐套 | 对应仓储发运 | 1–2 |
| **设备维修电工/机修工** | 激光、折弯、压力机保养维修 | 对应设备保全 | 1（可兼） |

### （三）技术与管理接口（非计件工种，但必配）

| 岗位 | 作用 |
|------|------|
| 车间主任 | 现场生产指挥 |
| 生产计划/物控 | 排产齐套、ERP |
| 工艺专员 | 折弯/冲压工艺卡、焊接工艺、工装 |
| 厂长 | 总责 |

### （四）可不作为一期固定工种（外协或兼岗）

| 工种 | 处理方式 |
|------|----------|
| 开平工 | 若外购开平板/卷板配送，可不配；若上开平线再配 |
| 铆工 | 装配仓以螺栓连接为主，铆工需求弱，并入装配 |
| 数控编程员 | 初期由激光工+工艺专员兼；量上来再单列 |
| 模具工 | 冲压模具外协维保，厂内会换模即可 |
| 电控装配工 | 按既有共识外协 |
| 起重司机（持证） | 与司索可一人双证或班组兼持 |

## 三、对照市场同类车间的配置逻辑

市场板仓/轻钢构车间通常分三条线：

1. **壁板线**：开平 → 冲孔压型（压力机）→ 折弯 → 检验包装 —— 工种以**冲压工、折弯工、激光/剪板工**为主。  
2. **结构件线**：下料 → 组对 → 焊接 → 打磨 —— 工种以**焊工、装配钳工**为主（立柱、仓顶、非标）。  
3. **涂装线**：抛丸/喷塑 —— 很多工厂**外协**，自建才养涂装班组。

实荣一期建议：**做实壁板线 + 结构件线，涂装能外协则外协**，与“核心自制、非标电控外协”原则一致；非标钢结构控制在结构件线产能弹性内，避免再铺一条全能钢构车间。

## 四、一期用工组合建议（贴合≤30人）

| 组别 | 工种构成 | 人数 |
|------|----------|------|
| 下料成型组 | 激光切割工 + 冲压工 + 折弯工 | 6–8 |
| 焊接装配组 | 电焊工 + 装配钳工（打磨兼） | 6–8 |
| 涂装 | 外协 或 涂装工 | 0–3 |
| 仓储发运 | 仓管（兼司索） | 2 |
| 质量/设备 | 质检、机修电工 | 2–3 |
| 管理接口 | 厂长、车间主任、计划、工艺、综合 | 5 |
| **合计** |  | **约22–28** |

## 五、一句话结论

粮仓装配仓工厂一期，围绕压力机、折弯机、激光与电焊，**必配工种是：激光切割工、冲压工、折弯工、电焊工、装配钳工**；辅以质检、仓管、机修；涂装与开平能外协则外协，编程/模具/电控不单设工种。
