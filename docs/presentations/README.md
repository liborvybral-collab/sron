# 经营汇报

管理层双周会上的经营汇报以 PPT 形式进行。本目录存放 **PPT 大纲及演讲备注**（Markdown），非 PPT 文件本身。

## 目录

| 类型 | 目录 |
|------|------|
| 管理层双周会经营汇报 | [management-biweekly/](management-biweekly/) |

## PPT 原件

PPT 原件存放说明见 `assets/presentations/`

## 使用说明

编写经营汇报时，AI 会综合：
- 三个部门当月月报
- 各专项最新进展
- 上期经营汇报和会议纪要

输出 PPT 大纲（每页：标题 + 要点 + 演讲备注）。
