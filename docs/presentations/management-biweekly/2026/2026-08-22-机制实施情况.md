# 项目打单-方案设计及报价机制实施情况（2026-08）

口径供管理层双周会口述。第一点按既定安排；第二点按「目的 → 两个维度盯重点 → 立项后全量闭环」重写，避免重点清单与全量跟踪混为一谈。

## 对外口径（文字模板）

关于方案设计及报价机制实施情况，本期抓两点。

一是，客户需求澄清会及方案评审会。每日下午5–6点，对当天提报任务管家的方案设计任务、以及当日完成的方案进行评审，把前置澄清与完成后评审压到同一天闭环。本项工作当前正常推进。

二是，在日常评审之外，把进入任务管家后的项目管到结果。日常评审解决的是当天方案质量；要形成打单闭环，还需按客户、项目两个维度做清单化管理，并覆盖管家内全部项目的去向。

客户维度：延续「客户大于项目」，对531战略客户建立重点客户清单，每月跟踪进展，并在月度会议上专项汇报。

项目维度：按转化阶段梳理三类重点项目——临签项目、报价决策项目、方案报价重点项目，同样清单化管理、每月跟踪、月度专项汇报，把资源压到高转化机会上。

在盯紧重点的同时，对上任务管家后的全部项目，按立项后状态持续跟踪（进行中 / 已结项-签约 / 已结项-丢单 / 暂停），确保每条任务都有去向、有结果，避免评审后脱管、过程中不闭环。

## 第二点逻辑结构（便于口述）

| 层次 | 管什么 | 怎么管 | 作用 |
|------|--------|--------|------|
| 目的 | 进任务管家之后的项目 | 从「当天评审」延伸到「管到结果」 | 补上方案/报价会之后的管理空白 |
| 客户维度 | 531战略客户 | 清单化；每月跟踪；月度会专项汇报 | 客户大于项目，盯山头 |
| 项目维度 | 临签、报价决策、方案报价重点三类 | 同上，按转化阶段压资源 | 近签约优先，方案报价重点保质量 |
| 全量闭环 | 管家内全部项目 | 立项后四态：进行中 / 已结项-签约 / 已结项-丢单 / 暂停 | 重点有人盯，全量有去向 |

三类重点项目由近及远：临签（即将转化）→ 报价决策（卡在价格/策略）→ 方案报价重点（前端集中兵力）。与每日下午评审衔接：评审管当天质量，清单管全过程结果。
