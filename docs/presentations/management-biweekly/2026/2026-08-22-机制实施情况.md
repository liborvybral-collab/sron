# 项目打单-方案设计及报价机制实施情况（2026-08）

口径供管理层双周会口述。第二点按用户最新表述梳理：总说节奏 → 客户维度 → 项目维度 → 本年度管家新建项目管到结项。

## 对外口径（文字模板）

关于方案设计及报价机制实施情况，本期抓两点。

一是，客户需求澄清会及方案评审会。每日下午5–6点，对当天提报任务管家的方案设计任务、以及当日完成的方案进行评审，把前置澄清与完成后评审压到同一天闭环。本项工作当前正常推进。

二是，按客户、项目两个维度做清单化管理，每月跟踪进展，并在业务月度会议上按小组汇报。

客户维度：按照「客户大于项目」管理原则，建立531战略客户清单。

项目维度：按转化阶段梳理三类重点项目——临签项目、报价决策项目、方案报价重点项目，把资源压到高转化机会上。

在盯紧上述重点的同时，对本年度任务管家新建项目实行清单化管理，跟踪立项后进展直至结项，确保每条设计任务都有去向、有结果。

## 第二点逻辑

| 层次 | 管什么 | 怎么管 |
|------|--------|--------|
| 总说 | 客户 + 项目两个维度 | 清单化；每月跟踪；业务月度会按小组汇报（节奏只说一次） |
| 客户维度 | 531战略客户 | 「客户大于项目」，建清单 |
| 项目维度 | 临签、报价决策、方案报价重点 | 按转化阶段分类，资源压到高转化机会 |
| 全量 | 本年度任务管家新建项目 | 立项后跟踪直至结项，每条设计任务有去向、有结果 |

客户、项目两段不再重复「每月跟踪、会上汇报」；全量段不并入月度会，只强调管到结项。
