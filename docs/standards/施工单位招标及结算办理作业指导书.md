# 施工单位招标及结算办理作业指导书

## 适用说明

本指导书是《施工单位招标及结算管理制度》的配套操作文件，供工程部、计划运营部、成本合约部、技术中心、预算部、现场项目经理及评标小组成员在日常招标评标定标、合同会签及结算办理中使用，明确工作步骤、时限、表单及注意事项。

制度管“谁负责、什么能做、什么不能做”；本指导书管“先做什么、后做什么、几天做完、表单怎么填”。

供应商库的日常扩充、入库、评价单独构成本指导书第三部分，与单次项目招标流程并行实施。

---

## 一、总体流程（招标—评标—定标—合同—结算）

```
招标启动 → 标书制作（清单+标底）→ 短名单（库内筛选+邀约）
    → 发标/答疑 → 报价收集与开标 → 专家评标 → 总经理定标
    → 合同拟定及会签 → 合同交底 → 进度结算/签证 → 竣工结算归档
```

四个核心环节的牵头部门不得变更：

| 环节 | 牵头部门 | 主要交付物 |
| --- | --- | --- |
| 标书制作 | 工程部 | 招标文件、工程量清单、标底测算表 |
| 供应商短名单确定 | 计划运营部 | 邀约记录、入围短名单 |
| 投标报价 | 成本合约部 | 发标记录、开标记录、报价分析表 |
| 专家评标 | 评标小组 | 评标报告、推荐供应商排序 |
| 定标及合同 | 总经理定标；成本合约部拟定合同 | 定标审批、合同及会签单 |
| 结算 | 工程部核量、成本合约部核价 | 进度结算、竣工结算、三价对比 |

---

## 二、招标评标定标操作流程

### 第1步 招标启动（工程部提出，3个工作日内）

施工发包需求明确后（图纸或方案可据以划分范围、业主合同施工义务已锁定、或现场必须发包），工程部填写《施工招标申请表》，内容包括：

- 项目名称、地点（国内/国别）、发包专业及范围、与业主合同界面；
- 估算金额、计划工期、计划进场时间；
- 技术重难点、甲供乙供划分；
- 建议招标方式（邀请招标/竞争性谈判/单一来源）及理由；
- 计划运营部、成本合约部会签后流转。

**操作要点：** 范围说不清的不启动；国际项目必须写明当地许可、是否允许使用当地承包商、支付币种。申请未批准，不得制作正式标书对外发出。

### 第2步 标书制作——工程量清单与技术文件（工程部牵头，一般10个工作日）

1. 工程部根据图纸、技术方案、现场条件编制施工范围说明和技术要求；复杂或海外项目书面征求技术中心意见。
2. 工程部拟定工程量清单：项目编码/名称、特征描述、计量单位、工程量、工作内容。预算部 3 个工作日内复核漏项、单位和计量规则。
3. 成本合约部同步准备投标须知、报价表、评标办法（综合评估法权重）、合同主要条款；计划运营部补入工期、交叉节点、供货衔接条款。
4. 内部审核：工程部组织计划运营部、成本合约部（必要时技术中心、预算部）召开标书审核会，填写《招标文件审核记录》，修改后定稿。

**清单质量底线：** 能量化的必须量化；不能量化的措施项目写清计算规则；禁止以“按实结算”“另行协商”代替清单。清单将直接用于结算，本步失误会在竣工阶段放大。

### 第3步 标底核算（工程部牵头，发标前完成，与第2步交叉进行）

1. 工程部结合技术方案、施工组织、当地价格水平测算标底，形成《标底测算表》（分部分项 + 措施费 + 风险 + 合理利润）。
2. 预算部复核人材机水平及含量；成本合约部复核类似中标价、结算价。
3. 标底确定后密封（或加密）保管，知悉范围仅限测算人、复核人及总经理。标底不得写入对外招标文件，评标时作为内部参考提交评标小组。

**异常规则：** 投标报价高于标底 15% 以上或低于标底 20% 以上的，评标时必须要求投标人书面澄清构成，不能合理说明的可判为不合理报价。

### 第4步 短名单拟定及邀约（计划运营部牵头，5个工作日+回函期）

1. 计划运营部按专业、区域、等级从供应商库检索，提出不少于 5 家候选（库内不足则启动临时准入或紧急扩充）。
2. 工程部 2 个工作日内确认技术能力是否匹配，可提出增补或剔除意见及理由。
3. 计划运营部向候选单位发出《投标邀请函》，要求在 3～5 个自然日内书面回复是否参标、联系人及是否踏勘。
4. 汇总回函，填写《入围供应商短名单审批表》：邀约家数、确认参标家数、不参标原因。有效参标意向原则上 ≥3 家，不足的补充邀约一轮；仍不足则按制度报总经理批准转换方式。
5. 总经理或授权领导批准短名单后，移交成本合约部发标。

**操作要点：** 邀约必须书面（邮件/函件），电话沟通只能作为预通知；未回复视为不参标并记录，作为后续评价依据。不得只邀约“关系熟、一定来”的两家凑数。

### 第5步 发标、踏勘与答疑（成本合约部牵头发标）

1. 成本合约部向短名单单位同步发出同一版本招标文件，记录发标时间及接收确认。
2. 需要踏勘的，工程部组织，计划运营部、成本合约部可派员；踏勘不单独向个别单位提供额外资料。
3. 投标人疑问在截止日前以书面提交；工程部答复技术问题，成本合约部答复商务问题，形成《答疑补遗纪要》，同时发送全部投标人。对清单数量、范围的修改视同招标文件变更，必要时顺延投标截止时间。

### 第6步 投标报价收集与开标（成本合约部牵头）

1. 投标文件在截止时间前送达成本合约部（或指定邮箱/平台），出具签收。逾期、未按格式、关键签字盖章缺失的，作废标，不开启报价（电子标除外，按投标须知）。
2. 截止后及时开标：成本合约部主持，工程部、计划运营部见证，宣读投标人、总价、工期等，填写《开标记录表》，见证人签字。
3. 成本合约部 2 个工作日内完成：符合性检查、算术修正、漏项识别、与标底对比、不平衡报价识别，形成《报价分析表》。算术错误按招标文件规则修正，修正后须投标人确认，不确认的可废标。

**符合性未通过不得进入评标打分。** 常见废标：范围漏报且拒绝补全、未响应关键工期、资格与短名单主体不一致（挂靠）。

### 第7步 组建评标小组并专家评标（收到报价分析后 3 个工作日内完成评标）

1. 计划运营部提出评标小组名单（技术中心、工程部、预算部、运营部、成本合约部，不少于 5 人单数），报总经理同意。与投标人有利害关系的回避。
2. 评标会议由组长主持，成本合约部介绍开标及报价分析（不诱导排名），工程部介绍技术要求及标底口径，计划运营部介绍短名单及资信。
3. 各专家按招标文件评分表独立打分或按评议法形成意见，不得会后补分。评审重点：

   - 技术中心/工程部：方案可行性、人员机具、质量安全、重难点措施；
   - 预算部：单价构成、不平衡报价、结算开口风险；
   - 运营部：工期、交叉、资源组织、国际项目当地合规；
   - 成本合约部：总价水平、付款与商务响应、合同风险。

4. 汇总形成《评标报告》：过程记录、废标说明、各家优劣、综合排序、**推荐供应商排序**及理由，全体成员签字。保留不同意见的，可在报告中注明。

**定标材料包：** 评标报告 + 开标记录 + 报价分析 + 短名单审批 + 招标申请，由计划运营部一并呈报总经理。

### 第8步 总经理定标（2个工作日）

总经理审定中标单位。一般确定推荐排序第一名；选择其后名次的，须在《定标审批表》书面说明。定标前不得向投标人透露排序。

定标后：成本合约部发中标通知；计划运营部通知未中标单位。中标单位无正当理由拒签合同的，可依次递补第二名，并对其作不良评价。

### 第9步 合同拟定及会签（成本合约部牵头，拟定 5 个工作日 + 会签 5 个工作日）

1. 成本合约部按中标价及招标文件合同条款起草合同，工程部提供技术附件和清单，计划运营部提供进度与协调条款。
2. 会签顺序：工程部 → 计划运营部 → 预算部（必要时）→ 财务部 → 成本合约部汇总 → 总经理批准 → 签署用印。
3. 会签人只对职责范围内的条款负责，意见写在《合同会签单》上，不得口头“原则同意”后不留痕。
4. 合同签订后 5 个工作日内组织交底，项目经理签字确认。

**禁止：** 在会签环节擅自变更中标价或实质性范围；确需调整的，应重新报请定标审批。

## 三、供应商库日常操作（与项目招标并行）

本部分由计划运营部归口，工程部、项目部、成本合约部配合。目标：尽快扭转“库内单位过少、短名单凑不够三家”的局面。

### （一）入库

1. 任何部门发现潜在施工单位，先填《施工单位入库申请表》并附执照、资质、业绩、联系人，交计划运营部。
2. 计划运营部 5 个工作日内形式审查；工程部组织考察或书面评估，填《施工单位考察评价表》。
3. 计划运营部组织会审定级（新入库一般为 C 级），编号建档，更新《施工单位供应商名录》并通报。
4. 紧急招标来不及正式入库的，走临时准入：基本资格审查 + 工程部书面评估，项目结束后 15 个工作日内补办入库。

### （二）扩充

计划运营部每季度初发布本季扩充计划（专业缺口、国别缺口、目标户数）。刚性要求：

- 现场项目经理、出国人员返回后 5 个工作日内移交当地施工队伍名录；
- 各部门每季度至少推荐线索，由计划运营部统计完成情况；
- 对土建、安装、当地劳务等缺口专业，可发布入库邀请公开征集。

名录应至少包含：单位全称、专业、区域、等级、联系人电话、合作项目、最近评价。

### （三）评价与清退

合同履约结束 15 个工作日内，工程部、项目部、成本合约部完成履约评价，计划运营部调级。出现转包挂靠、质量安全事故主责、围标、弃标拒签、恶性欠薪、行贿的，直接 D 级清退并通报。

## 四、结算办理流程

### 第10步 进度结算

1. 施工单位按合同周期申报进度工程量及影像/验收资料。
2. 项目经理审核现场真实性（2 个工作日）→ 工程部复核工程量（3 个工作日）→ 成本合约部按合同单价计价（3 个工作日）→ 计划运营部核对付款节点 → 总经理/授权审批 → 财务部付款。
3. 资料不齐、量价不符、超形象进度的，退回补正，不进入付款。

### 第11步 签证结算

按《项目签证办理作业指导书》执行：一事一签、当天原始记录、完工后 7 个自然日内申报；签证会审一般只审工程量，单价按合同或另行报批。招标清单内项目不得以签证重复申报。

### 第12步 竣工结算

1. 完工后，项目经理汇总合同内结算 + 全部有效签证 + 扣款，编《项目完工预结算汇总表》。
2. 工程部、计划运营部、成本合约部依次审核，总经理审批后谈判确认。
3. 成本合约部 10 个工作日内完成标底—中标价—结算价三价对比，归档并反馈偏差原因（漏项、签证、涨价、范围变化等），用于下一次标底和短名单改进。
4. 工程部移交财务部支付至质保节点。

### 争议处理

- 投标人对评标、废标有异议：开标/评标结果告知后 3 个工作日内书面提出，评标小组答复，计划运营部备案。
- 施工单位对结算有异议：工程部主导，计划运营部、成本合约部配合，10 个工作日内协商；不成则报总经理裁决。可搁置争议项，先办理无争议部分结算。

## 五、文件填写规范

### （一）招标申请表

项目名称须与业主合同一致；发包范围用“包含/不包含”双向写清；估算金额与计划工期不得空白；单一来源必须写法定或业主指定依据。

### （二）工程量清单

计量单位与合同、图纸一致；工程量为可计算数值；特征描述含部位、规格、做法；措施项目列计算规则。不得写“一套”“一式”“若干”。

### （三）标底测算表

列示编制依据（图纸版次、价格时点、费率）、分项合价、不可竞争费用（如有）、风险费。封面标注密级及知悉人。

### （四）投标邀请函与短名单

邀请函载明项目概况、文件获取方式、截止时间、联系人；短名单表须有库内编号、等级、邀约结果。临时准入单位单独标注。

### （五）开标记录与评标报告

开标记录不得涂改总价；评标报告必须有推荐排序（至少两名候选人，有效投标仅一家的除外）及全体签字。禁止只写“建议某某中标”而无比较分析。

### （六）合同会签单

会签人写明“同意 / 修改意见 / 不同意”，修改意见须具体到条款。空签、代签无效。

### （七）结算报审

申报量必须源于现场计量或签证原始记录；计价必须引用合同单价编号；扣款列明依据。竣工结算附件应含签证台账目录，与计划运营部归档签证一一对应。

## 六、常见问题与注意事项

**问题1：库里没几家，短名单凑不够三家。**  
正确做法：先启动扩充和临时准入，补充邀约；仍不足时书面说明已检索范围、已邀约对象及拒绝原因，报总经理批准后竞争性谈判或单一来源。禁止长期用“就这两家”跳过审批。

**问题2：标书只有范围说明，没有清单和标底，直接要单位报个总价。**  
正确做法：必须先有工程量清单和内部标底再发标。总价包干可以，但包干范围、工作内容、风险边界仍须在标书中写清，否则结算必争。

**问题3：工程部已经内定某单位，评标走形式。**  
正确做法：短名单由计划运营部牵头，评标由跨部门小组推荐，总经理定标。任何部门可推荐，但不得指定唯一中标人。内定线索可作为推荐入库理由，不能替代四环节。

**问题4：开标前已知道各家报价。**  
正确做法：报价收至截止时间统一开启，见证人到场。提前拆阅视为违规。电子邮箱投标应设置截止前不下载或双人开启。

**问题5：评标只看谁便宜。**  
正确做法：综合评估，合理低价。明显低于标底且人员机具配置不足的，应判履约风险，不得推荐为第一名。

**问题6：中标后再谈降价、砍范围。**  
正确做法：实质性条件以定标为准。范围增加走签证或补充协议并履行审批，不得以“再让一点”代替合同会签。

**问题7：先让队伍进场，合同后补、结算按实。**  
正确做法：除抢险抢工并在 5 个工作日内补签外，禁止无合同施工。先干后补导致的范围和价格争议，由擅自安排进场的人员承担责任。

**问题8：结算价远超中标价，无人分析。**  
正确做法：竣工后必须做三价对比。偏差大的，要分清是清单漏项、现场签证、还是招标范围不清，并回头修订标书模板和短名单评价。

**问题9：海外当地包工头无法提供国内式资质。**  
正确做法：以当地合法主体、考察评价、临时准入为主，简化形式、不简化现场能力核实；资料仍须建档，纳入供应商库 C 级培育。

**问题10：各部门各存一份供应商名单，互不共享。**  
正确做法：统一交计划运营部入库。私库单位未入库的，不得进入短名单。

## 七、时限一览

| 步骤 | 责任部门 | 时限 |
| --- | --- | --- |
| 提出招标申请 | 工程部 | 需求明确后 3 个工作日 |
