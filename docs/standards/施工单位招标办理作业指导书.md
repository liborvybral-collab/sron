# 施工单位招标办理作业指导书

## 适用说明

本指导书是《施工单位招标管理制度》的配套操作文件，供工程部、计划运营部、成本合约部（含预决算）、技术中心、现场项目经理及评标小组成员在日常招标、评标、定标及合同会签中使用，明确工作步骤、时限、表单及注意事项。

制度管“谁负责、什么能做、什么不能做”；本指导书管“先做什么、后做什么、几天做完、表单怎么填”。

过程签证、施工结算及施工单位供应商库管理不在本指导书范围内，另行执行公司相关制度。成本合约部与预决算为同一部门，本指导书统称成本合约部（含预决算）。

计划运营部为施工单位招标总负责部门，并牵头短名单确定和专家评标组织。

---

## 一、总体流程（招标—评标—定标—合同）

```
招标启动 → 标书制作（清单+标底）→ 短名单（筛选+邀约）
    → 发标/答疑 → 报价收集与开标 → 专家评标 → 总经理定标
    → 合同拟定及会签 → 合同交底 → 归档
```

四个核心环节的牵头部门不得变更：

| 环节 | 牵头部门 | 主要交付物 |
| --- | --- | --- |
| 招标总负责 | 计划运营部 | 计划督办、评标组织、定标呈报、档案 |
| 标书制作 | 工程部 | 招标文件、工程量清单、标底测算表 |
| 供应商短名单确定 | 计划运营部 | 邀约记录、入围短名单 |
| 投标报价 | 成本合约部 | 发标记录、开标记录、报价分析表 |
| 专家评标组织 | 计划运营部 | 评标会、评标报告（小组集体签字） |
| 定标及合同 | 总经理定标；成本合约部拟定合同 | 定标审批、合同及会签单 |

## 二、招标评标定标操作流程

### 第1步 招标启动（工程部提出，3个工作日内）

施工发包需求明确后（图纸或方案可据以划分范围、业主合同施工义务已锁定、或现场必须发包），工程部填写《施工招标申请表》，内容包括：

- 项目名称、地点（国内/国别）、发包专业及范围、与业主合同界面；
- 估算金额、计划工期、计划进场时间；
- 技术重难点、甲供乙供划分；
- 建议招标方式（邀请招标/竞争性谈判/单一来源）及理由；
- 计划运营部、成本合约部会签后流转。

**操作要点：** 范围说不清的不启动；国际项目必须写明当地许可、是否允许使用当地承包商、支付币种。申请未批准，不得制作正式标书对外发出。

### 第2步 标书制作——工程量清单与技术文件（工程部牵头，一般10个工作日）

1. 工程部根据图纸、技术方案、现场条件编制施工范围说明和技术要求；复杂或海外项目书面征求技术中心意见。
2. 工程部拟定工程量清单：项目编码/名称、特征描述、计量单位、工程量、工作内容。成本合约部（预决算）3 个工作日内复核漏项、单位和计量规则。
3. 成本合约部同步准备投标须知、报价表、评标办法（综合评估法权重）、合同主要条款；计划运营部补入工期、交叉节点、供货衔接条款。
4. 内部审核：工程部组织计划运营部、成本合约部（必要时技术中心）召开标书审核会，填写《招标文件审核记录》，修改后定稿。

**清单质量底线：** 能量化的必须量化；不能量化的措施项目写清计算规则；禁止以“按实结算”“另行协商”代替清单。清单不清，后续合同和现场必争。

### 第3步 标底核算（工程部牵头，发标前完成，与第2步交叉进行）

1. 工程部结合技术方案、施工组织、当地价格水平测算标底，形成《标底测算表》（分部分项 + 措施费 + 风险 + 合理利润）。
2. 成本合约部（预决算）复核人材机水平、含量及类似中标价。
3. 标底确定后密封（或加密）保管，知悉范围仅限测算人、复核人及总经理。标底不得写入对外招标文件，评标时作为内部参考提交评标小组。

**异常规则：** 投标报价高于标底 15% 以上或低于标底 20% 以上的，评标时必须要求投标人书面澄清构成，不能合理说明的可判为不合理报价。

### 第4步 短名单拟定及邀约（计划运营部牵头，5个工作日+回函期）

1. 计划运营部按专业、区域、工期及能力要求提出候选单位，工程部 2 个工作日内确认技术能力是否匹配，可提出增补或剔除意见及理由。
2. 计划运营部向候选单位发出《投标邀请函》，要求在 3～5 个自然日内书面回复是否参标、联系人及是否踏勘。
3. 汇总回函，填写《入围供应商短名单审批表》：邀约家数、确认参标家数、不参标原因。有效参标意向原则上 ≥3 家，不足的补充邀约一轮；仍不足则按制度报总经理批准转换方式。
4. 总经理或授权领导批准短名单后，移交成本合约部发标。

**操作要点：** 邀约必须书面（邮件/函件），电话沟通只能作为预通知；未回复视为不参标并记录。不得只邀约“关系熟、一定来”的两家凑数。

### 第5步 发标、踏勘、答疑澄清与补遗（成本合约部牵头，工程部技术澄清）

本步多为反复过程，可能多轮，不是发完标就等截止。

1. 成本合约部向短名单单位同步发出同一版本招标文件，建立收发台账（发标时间、版本、接收确认）。
2. 需要踏勘的，工程部组织，计划运营部、成本合约部可派员；踏勘不单独向个别单位提供额外资料。
3. 投标人疑问一律书面提交。工程部在约定时限内书面答复技术问题（范围、图纸、做法、工程量），成本合约部书面答复商务及报价口径问题（单价构成、漏项、税费、付款等）。成本合约部汇总形成《答疑补遗纪要》，**同时发送全部投标人**，禁止一对一电话定口径。
4. 澄清导致清单、范围或做法变化的，成本合约部发补遗，并评估是否顺延投标截止时间。同一项目允许多轮答疑，每轮均须书面留痕。重大技术问题未澄清完的，不得直接收标。

### 第6步 收标、开标、开标后澄清与报价分析（成本合约部牵头）

1. 投标文件在截止时间前送达成本合约部（或指定邮箱/平台），出具签收。逾期、未按格式、关键签字盖章缺失的，作废标，不开启报价（电子标除外，按投标须知）。
2. 截止后及时开标：成本合约部主持，工程部、计划运营部见证，宣读投标人、总价、工期等，填写《开标记录表》，见证人签字。开启前任何人不得查阅报价。
3. 开标后成本合约部做符合性检查、算术修正、漏项识别、与标底对比、不平衡报价识别。对需要投标人说明的，书面发出澄清函并限时回复；修正后须投标人确认，不确认的可废标。澄清不得改变实质性投标条件和总价竞争基础。
4. 形成《报价分析表》提交评标小组。符合性未通过不得进入评标打分。一对口头头沟通不得写入分析表。

**常见废标：** 范围漏报且拒绝补全、未响应关键工期、资格与短名单主体不一致（挂靠）。

### 第7步 组建评标小组并专家评标（计划运营部牵头组织，收到报价分析后 3 个工作日内完成）

1. 计划运营部提出评标小组名单（技术中心、工程部、计划运营部、成本合约部，不少于 5 人单数；成本合约部可派预决算人员与合约人员各 1 人），报总经理同意。组长一般由计划运营部负责人担任，成本合约部不担任组长。与投标人有利害关系的回避。
2. 评标会议由计划运营部召集、组长主持。成本合约部介绍开标及报价分析（不诱导排名），工程部介绍技术要求及标底口径，计划运营部介绍短名单及资信。
3. 各专家按招标文件评分表独立打分或按评议法形成意见，不得会后补分。评审重点：

   - 技术中心/工程部：方案可行性、人员机具、质量安全、重难点措施；
   - 成本合约部（预决算）：单价构成、不平衡报价、价格开口风险；
   - 成本合约部（合约）：总价水平、付款与商务响应、合同风险；
   - 计划运营部：工期、交叉、资源组织、国际项目当地合规。

4. 计划运营部汇总形成《评标报告》：过程记录、废标说明、各家优劣、综合排序、**推荐供应商排序**及理由，全体成员签字。保留不同意见的，可在报告中注明。计划运营部不得在汇总时改写小组成员意见。

**定标材料包：** 评标报告 + 开标记录 + 报价分析 + 短名单审批 + 招标申请，由计划运营部一并呈报总经理。

### 第8步 总经理定标（2个工作日）

总经理审定中标单位。一般确定推荐排序第一名；选择其后名次的，须在《定标审批表》书面说明。定标前不得向投标人透露排序。

定标后：成本合约部发中标通知；计划运营部通知未中标单位。中标单位无正当理由拒签合同的，可依次递补第二名，并对其作不良评价。

### 第9步 合同拟定及会签（成本合约部牵头，拟定 5 个工作日 + 会签 5 个工作日）

1. 成本合约部按中标价及招标文件合同条款起草合同，工程部提供技术附件和清单，计划运营部提供进度与协调条款。
2. 会签顺序：工程部 → 计划运营部 → 成本合约部（含预决算）→ 财务部 → 成本合约部汇总 → 总经理批准 → 签署用印。
3. 会签人只对职责范围内的条款负责，意见写在《合同会签单》上，不得口头“原则同意”后不留痕。
4. 合同签订后 5 个工作日内组织交底，项目经理签字确认。

**禁止：** 在会签环节擅自变更中标价或实质性范围；确需调整的，应重新报请定标审批。

### 争议处理

投标人对评标、废标有异议：开标或评标结果告知后 3 个工作日内书面提出，由计划运营部受理，评标小组答复并备案。招标、定标重大争议报总经理裁决。

## 三、文件填写规范

### （一）招标申请表

项目名称须与业主合同一致；发包范围用“包含/不包含”双向写清；估算金额与计划工期不得空白；单一来源必须写法定或业主指定依据。

### （二）工程量清单

计量单位与图纸、技术要求一致；工程量为可计算数值；特征描述含部位、规格、做法；措施项目列计算规则。不得写“一套”“一式”“若干”。

### （三）标底测算表

列示编制依据（图纸版次、价格时点、费率）、分项合价、不可竞争费用（如有）、风险费。封面标注密级及知悉人。

### （四）投标邀请函与短名单

邀请函载明项目概况、文件获取方式、截止时间、联系人；短名单表须有邀约结果。

### （五）开标记录与评标报告

开标记录不得涂改总价；评标报告必须有推荐排序（至少两名候选人，有效投标仅一家的除外）及全体签字。禁止只写“建议某某中标”而无比较分析。计划运营部汇总报告时不得改变成员意见。

### （六）合同会签单

会签人写明“同意 / 修改意见 / 不同意”，修改意见须具体到条款。空签、代签无效。

## 四、常见问题与注意事项

**问题1：短名单凑不够三家。**  
正确做法：补充邀约；仍不足时书面说明已邀约对象及拒绝原因，报总经理批准后竞争性谈判或单一来源。禁止长期用“就这两家”跳过审批。

**问题2：标书只有范围说明，没有清单和标底，直接要单位报个总价。**  
正确做法：必须先有工程量清单和内部标底再发标。总价包干可以，但包干范围、工作内容、风险边界仍须在标书中写清。

**问题3：工程部已经内定某单位，评标走形式。**  
正确做法：短名单和评标组织由计划运营部牵头，评审由跨部门小组集体作出，总经理定标。任何部门可推荐，但不得指定唯一中标人。计划运营部不得诱导排名。

**问题4：开标前已知道各家报价。**  
正确做法：报价收至截止时间统一开启，见证人到场。提前拆阅视为违规。电子邮箱投标应设置截止前不下载或双人开启。

**问题5：评标只看谁便宜。**  
正确做法：综合评估，合理低价。明显低于标底且人员机具配置不足的，应判履约风险，不得推荐为第一名。

**问题6：中标后再谈降价、砍范围。**  
正确做法：实质性条件以定标为准。范围增加须签订补充协议并履行审批，不得以“再让一点”代替合同会签。

**问题8：报价阶段一对一电话把口径说了，别的单位不知道。**  
正确做法：所有澄清必须书面，由成本合约部汇总后同时发给全部短名单单位。技术问题工程部答，商务问题成本合约部答，计划运营部盯时限。口头沟通不能当评标依据。

## 五、时限一览

| 步骤 | 责任部门 | 时限 |
| --- | --- | --- |
| 提出招标申请 | 工程部 | 需求明确后 3 个工作日 |
| 标书及清单 | 工程部（成本合约部预决算复核 3 个工作日） | 一般 10 个工作日（复杂项目书面延期） |
| 标底 | 工程部组织，成本合约部复核 | 发标前完成 |
| 短名单筛选及内部确认 | 计划运营部 + 工程部 | 5 个工作日 |
| 邀约回函 | 被邀约单位 | 3～5 个自然日 |
| 投标编制 | 投标单位 | 标书约定，一般 7～15 个自然日 |
| 发标后答疑澄清补遗 | 成本合约部牵头，工程部技术澄清 | 随疑问发生，书面同步全部投标人；重大澄清评估是否顺延截止时间 |
| 报价分析及开标后澄清 | 成本合约部牵头，工程部配合 | 开标后组织书面澄清，分析表随澄清完成提交评标 |
| 专家评标组织 | 计划运营部（评标小组评审） | 3 个工作日 |
| 定标 | 总经理 | 2 个工作日 |
| 合同拟定 | 成本合约部 | 5 个工作日 |
| 合同会签 | 各部门 | 5 个工作日 |
| 合同交底 | 成本合约部组织 | 签约后 5 个工作日 |

紧急项目压缩时限须在招标申请中列明，并保证“短名单批准 → 书面发标 → 评标报告 → 定标 → 合同”五项痕迹齐全。
