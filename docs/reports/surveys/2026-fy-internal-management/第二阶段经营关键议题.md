# 《公司调研重大议题讨论会》议题清单

**会议目的：** 基于内部调研，按经营分析框架统一下半年方向；每个议题当场形成决议 / 试点 / 暂缓（须写明理由）。

**讨论规则：** 先亮观点、再对方向、最后定责任人与时间；不对着部门互相指责，对准可执行结论。

---

## 一、产品定位

**要解决的问题：** 下半年到底主打什么、不做什么，差异化与第二曲线、工厂建设如何定。

| 序 | 讨论命题（请拍板） | 建议结论形式 |
|----|--------------------|--------------|
| 1.1 | 公司产品如何定义：是“解决方案/系统集成”，还是“解决方案系统 + 核心产品”？核心产品是什么？ | 一句话产品定义 + 核心产品名单（1–3 项） |
| 1.2 | 产品差异化抓哪几条？对外能讲、对内能交付的差异化是什么？ | 差异化要点 ≤3 条；无能力支撑的口径停用 |
| 1.3 | 主航道行业定哪 2–3 个？明确不做什么（负面清单）？ | 主航道名单 + 负面清单 1–3 条 |
| 1.4 | 第二曲线先验证哪 1 条？（如旧仓改造/运维、工业散料延伸等）投入上限与退出标准是什么？ | 选定 1 条 + 投入/退出标准 |
| 1.5 | 工厂建设：全面自建、参股/租赁绑定产能，还是暂缓？若推进，先试点什么品类、何时复评？ | 决议：推进路径 / 试点范围 / 暂缓理由与复评时间 |

**会后产物：** 《产品定位与主航道一页纸》

**建议主责：** 经营层牵头；市场战略、技术/研发、品牌、业务协同

---

## 二、市场营销

**要解决的问题：** 打单成功率怎么提上去，品牌与市场机会怎么服务成单。

| 序 | 讨论命题（请拍板） | 建议结论形式 |
|----|--------------------|--------------|
| 2.1 | 怎么提升项目打单成功率？线索/项目是否强制三级分类（战略/重点/一般）？每级响应深度与时限？ | 《打单分级与响应规则》及上线时间 |
| 2.2 | 提资前置：物料、流程、范围、品牌、决策人等未澄清，技术可否退回？ | 退回机制：是 / 否 + 清单字段 |
| 2.3 | 报价是否试点高/中/低分档？成单/丢单是否进入月度经营会固定复盘？ | 试点范围 + 复盘责任部门 |
| 2.4 | 品牌运营怎么优化？重点项目是否强制素材采集？展会线索如何闭环沉淀？ | 2–3 条强制动作 + 责任部门（品牌+业务+工程） |
| 2.5 | 市场机会抓哪里？下半年重点国别/行业/公海二次开发怎么排优先级？ | 重点机会清单（≤5）+ 资源配比原则 |

**会后产物：** 《市场营销与打单提效一页纸》

**建议主责：** 业务部牵头；品牌运营、市场战略、客户管理、技术、成本招采协同

---

## 三、经营管理

**要解决的问题：** 项目执行效率、部门协同、标准化流程，以及大项目怎么协同作战。

| 序 | 讨论命题（请拍板） | 建议结论形式 |
|----|--------------------|--------------|
| 3.1 | 怎么提升项目执行效率？计划运营总控是否对技术/采购/质检/物流/工程具约束力并挂钩考核？ | 总控权责边界 + 考核挂钩方式 |
| 3.2 | 质量与交付闸门：供应商分级、发货前质检能否拦发货？产能触顶后排产、外协还是控制接单承诺？ | 闸门规则 + 产能触顶规则 |
| 3.3 | 如何做好大项目协作？大项目认定标准是什么？是否实行铁三角/专班？资源如何锁定？ | 《大项目协作机制》 |
| 3.4 | 如何做好跨部门协同？下半年先打通哪 2–3 条关键接口？（如：提资前置↔技术退回；提资↔物流证书包装↔招采；质检↔发货闸门；节点↔考核） | 接口清单 + 主责/时限/逾期后果 |
| 3.5 | 标准化流程先梳理哪几条？（建议不超过 3 条，如：提资、变更、完工复盘） | 流程清单 + 责任部门 + 完成节点 |

**会后产物：** 《经营管理与执行总控一页纸》+《关键接口权责时限表》

**建议主责：** 计划运营部牵头；技术、成本招采、质监、物流、工程、业务协同

---

## 四、核心竞争力打造

**要解决的问题：** 竞争态势怎么看，实荣相对强弱在哪，下半年凭什么赢。

| 序 | 讨论命题（请拍板） | 建议结论形式 |
|----|--------------------|--------------|
| 4.1 | 竞争态势研判：主要对手是谁？我们赢单/丢单的常见原因是什么？ | 对手名单 + 赢/丢单原因 Top3 |
| 4.2 | 实荣 SWOT：优势、劣势、机会、威胁各写清 3 条以内（要能指导下半年动作，不做完整学术 SWOT） | SWOT 简表（每格 ≤3 条） |
| 4.3 | 如何塑造自身核心竞争力？对外一句话竞争力定哪句？今明两年各优先加固哪 1–2 项能力？ | 竞争力定义卡 + 加固动作清单 |

**说明：** 本板块与“产品定位”分工——产品定位定“做什么”；本板块定“凭什么赢、相对对手强在哪”。

**会后产物：** 《核心竞争力定义卡》+ SWOT 简表 + 加固动作（责任/里程碑）

**建议主责：** 经营层牵头；市场战略、业务、技术、工程、品牌协同
