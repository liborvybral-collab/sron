# 2026年中经营分析会 · 第二阶段经营关键议题

**阶段定位：** 内部调研已完成。本阶段议题**直接聚焦调研中员工集中提出的经营问题**，由管理层专题讨论，形成下半年可执行方向。

**议题原则：**
- 议题表述对齐调研原题与高频痛点，不另起一套“空战略话术”。
- 数量控制在 **5 个以内**；每个议题当场形成：方向判断 + 责任部门 + 下半年动作。
- 双休/考勤/报销等员工体验问题另作组织回应，不占本阶段经营五题。

## 议题说明（讨论提纲）

### 议题 1：如何塑造公司核心竞争力？

**调研在问什么：** 应如何构建公司的核心竞争力？产品与赛道如何定位？

**员工共识画像（组合竞争力，而非单一产品）：**
- 大宗散料智慧储运 **EPC / 系统交付**能力  
- 重点行业**工艺与场景深度**（水泥、粮食、港口、矿产等）  
- **履约与交付口碑**（海外圈子小，口碑即获客）  
- **技术研发与差异化**（智能监测、特殊物料等可售卖能力）  
- 人才与组织能力  

**尖锐信号：** 无拳头产品、参观无样品、过度依赖价格与关系；“什么都能做、什么都不精”。

**会上请拍板：**
1. 一句话竞争力定义（≤40 字），业务/技术/工程/品牌能共同对外说。  
2. 哪些是“现在就能赢单的”，哪些是“明年要建成的”。  
3. 主航道定 2–3 个行业；明确 1–3 条负面清单（不做什么）；第二曲线只选 1 条验证。

**会后产物：** 《核心竞争力定义卡》+《主航道与负面清单一页纸》

---

### 议题 2：怎么提升项目打单成功率？

**调研在问什么：** 线索分配、客户开发、方案设计、项目报价等，现状问题与可落地方案。

**问题画像：**
- 询盘多、有效商机少；比价型线索消耗技术资源  
- 跟进不彻底、渠道单一、公海与线索闭环弱  
- 需求未澄清就提技术任务；方案时间被挤、质量不稳  
- 报价偏高或一刀切，缺少分档与竞对复盘  

**会上请拍板：**
1. 线索/项目三级（战略/重点/一般）是否**强制执行**，每级响应深度与时限。  
2. 提资前置清单未齐备，技术可否**退回**。  
3. 一般线索标准化快响 vs 重点项目吃饱资源。  
4. 高/中/低分档报价是否试点；成单/丢单是否进入月度经营会固定复盘。

**会后产物：** 《项目筛选与打单响应规则》及上线时间（业务 + 技术 + 成本招采 + 计划运营）

---

### 议题 3：怎么提升项目执行效率与交付质量？

**调研在问什么：** 深化设计、物资采购、质检、发货、工程施工等，影响交付效率与质量的实际问题。

**问题链条（高度一致）：**  
深化设计滞后或不深 → 采购节奏乱/供应商质量不稳 → 质检与物资信息不对称 → 发货与现场脱节 → 赶工返工、劳务波动 → 口碑与成本双损。

**会上请拍板：**
1. 计划运营是否具备对技术/采购/质检/物流/工程的**节点约束与考核挂钩**权。  
2. 启动交底、变更书面纪要、完工复盘是否强制。  
3. 供应商分级、发货前质检（尤其焊接与细节）能否**拦发货**。  
4. 设计/加工/发货产能触顶后：排产、外协，还是控制接单承诺。  
5. 现场问题先止损复产，再复盘定责。

**会后产物：** 《项目执行总控与质量闸门规则》

---

### 议题 4：如何做好大项目协作？

**调研在问什么：** 打单与执行交叉中，重点/大型项目如何集中资源、避免“人人都说自己的项目是好项目”。

**问题画像：**
- 缺少清晰的“大项目/战略项目”认定标准，资源平均用力  
- 业务—技术—成本“铁三角”喊得多、机制少；技术赋能业务不足  
- 大项目变更多、现场权限不清，跨部门扯皮后置到施工末端  
- 前端合同谈判未给深化/采购留工期余量，大项目更容易爆雷  

**会上请拍板：**
1. **大项目定义**：金额、战略客户、复杂度、国别等标准（谁认定、多久认定一次）。  
2. **协作机制**：是否成立铁三角/项目专班；例会节奏；信息共享平台要求。  
3. **授权边界**：现场紧急处置权限；变更书面闭环谁签字。  
4. **资源锁定**：大项目是否优先锁定技术骨干、采购与施工窗口，禁止被一般询盘挤占。

**会后产物：** 《大项目协作机制》（定义 + 组织 + 授权 + 资源锁定）

---

### 议题 5：如何提升跨部门协同效率？

**调研在问什么：** 跨部门协同是全卷最高频组织议题之一（约 45%）；效率题中信息差、会议低效、权责不清反复出现。

**问题画像：**
- 部门内部氛围尚可，公司跨部门紧张、推诿、各自为战  
- 会议长、易变“告状会”；真正打磨少  
- 典型断点：提资、返资/说明书、质检—物资信息、发货—现场节奏、合同多头归档等  

**会上请拍板（只选 2–3 条先打通，勿摊大饼）：**
1. 业务提资前置 ↔ 技术退回  
2. 技术提资 ↔ 物流证书/包装 ↔ 成本招采  
3. 质检信息 ↔ 物资/发货闸门  
4. 计划运营节点 ↔ 各部门考核  
5. 成单/丢单/完工复盘 ↔ 经营会固定输入  

每条接口写清：主责、时限、逾期后果。

**会后产物：** 《下半年关键接口权责时限表》

**①如何塑造核心竞争力；②怎么提升打单成功率；③怎么提升项目执行效率与交付质量；④如何做好大项目协作；⑤如何提升跨部门协同效率。**
