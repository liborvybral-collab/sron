# 2026财年内部管理调研 · 管理层关键议题清单

**会议目的：** 第一阶段员工意见已收集。本次部门长联席围绕以下 6 个议题充分讨论，形成下半年可执行方向（决议 / 试点 / 暂缓须写明理由）。

**讨论规则：** 每题先亮观点、再对方向、最后定责任人与时间；不对着部门互相指责，对准公司目标与跨部门接口。

## 议题 1：我们到底靠什么赢——公司核心竞争力如何定义？

**为什么要议：** 大家口头都认同 EPC、专业、口碑、技术、人才，但并不统一。定义不清，后面赛道、打单、交付、建厂都会各说各话。

**建议讨论方向（选一为主，另选至多两项作支撑）：**
- A. **系统交付能力**：大宗散料智慧储运 EPC / 交钥匙（方案—供应链—施工—调试—售后）
- B. **行业专业深度**：在水泥 / 粮食 / 港口 / 矿产等重点行业“更懂工艺、更能解决痛点”
- C. **履约口碑**：海外圈子靠交付信誉吃饭，按时高质量履约即获客
- D. **技术差异化**：智能监测、特殊物料工艺等可售卖、可单独计价的能力
- E. **制造与供应链掌控**：交期、成本、样品可控（含绑定产能），缓解集成商被动

**会上请拍板：**
1. 一句话定义（不超过 40 字），业务 / 技术 / 工程 / 品牌能共同对外说。  
2. 哪些是“今天已经能赢单的”，哪些是“明年要建成的”——愿望不要写成现状。  
3. 下半年禁止再主打的口径（没有能力支撑的话不说）。

**会后产物：** 《核心竞争力定义卡》+ 加固动作清单（责任部门 / 里程碑）。

## 议题 2：产品与业务是聚焦主航道，还是继续多元化？不做什么？

**为什么要议：** 询盘面宽、行业杂，员工担心“什么都能做、什么都不精”。资源有限，必须先定战场，再谈打仗。

**建议讨论方向：**
- **主航道（重点投入）**：建议从水泥建材、粮食储运、港口散货、矿产/能源中选定 **2–3 个**。  
- **机会型（可接单、不主动铺资源）**：写清边界。  
- **负面清单（明确不做什么）**：如与储运弱相关的旁支、纯单机贸易、无工艺支撑的跨行业“什么都报”等——请当场列出 1–3 条。  
- **第二曲线**：只选 **1 条**先验证（如旧仓改造/运维，或工业散料延伸），并设投入上限与退出标准。

**会上请拍板：**
1. 主航道名单；机会型名单；不做什么名单。  
2. 资源配比原则（如主航道约 70%、试验约 30%）。  
3. 对外产品叙事是否统一（避免口径打架）。

**会后产物：** 《下半年主航道与负面清单一页纸》。

## 议题 3：项目怎么筛、资源怎么配，才能提高成单率？

**为什么要议：** 澄清会、评审会、分级已在推进，但成单率仍低、无效方案仍消耗技术。问题不是“有没有会”，而是**筛选与响应有没有牙齿**。

**建议讨论方向：**
1. **项目/线索三级分类**（战略 / 重点 / 一般）——每级谁上、做到多深、多少天内给结论。  
2. **提资前置**：物料、流程、范围、品牌、决策人等未澄清，技术可否退回。  
3. **资源保护**：一般类线索标准化快响，不深耗骨干；重点项目吃饱资源。  
4. **报价与复盘**：是否试点高/中/低分档；成单/丢单是否进入月度经营会固定复盘。

**会上请拍板：**
- 分级标准是否强制执行；退回机制是否生效；复盘谁交材料、何时上会。

**会后产物：** 《项目筛选与响应规则》+ 上线时间（业务 + 技术 + 总经办）。

## 议题 4：项目执行总控怎么建，才能稳交付、保口碑？

**为什么要议：** 计划运营督办与组织奖金考核已在跑，但设计—采购—质检—发货—现场仍易断链；例会已提出交付产能与发货体量匹配问题。要决定：总控是“提醒”，还是“有权有责”。

**建议讨论方向：**
1. **总控权责**：全景节点是否对技术 / 采购 / 质检 / 物流 / 工程具约束力，延期能否考核到部门。  
2. **三项强制动作**：启动交底、变更书面纪要、完工复盘——是否强制、谁召集。  
3. **质量闸门**：供应商分级、发货前质检（尤其焊接与细节）能否拦发货。  
4. **产能上限**：月度设计 / 加工 / 发货可承载量是否有数；触顶后是排产、外协还是控制接单承诺。  
5. **处置原则**：现场问题先止损复产，再复盘定责；安全与重大质量一票否决。

**会上请拍板：**
- 总控权限边界；强制动作清单；考核挂钩方式；产能触顶规则。

**会后产物：** 《项目执行总控要点》三页内（权责 + 强制动作 + 考核）。

---

## 议题 5：跨部门协同卡在哪，下半年先打通哪几条？

**为什么要议：** 部门内往往还能转，公司层容易各自为战、信息差、会议变长。不求一次理顺所有流程，但必须选出下半年能打穿的关键接口。

**建议优先勾选（最多 3 条）：**
| 接口 | 典型问题 | 讨论方向 |
|------|----------|----------|
| 业务 ↔ 技术 | 需求未清就提资、方案反复 | 提资清单 + 预审退回 + 排期规则 |
| 设计 ↔ 采购 ↔ 质检 | 进度与质量各说各话 | 统一台账 + 拦货标准 + 升级路径 |
| 发货 ↔ 现场 | 窝工或积压 | 发货听现场 + 冲突由计划运营裁决 |
| 保障 ↔ 一线 | 报销/票务/盖章拖节奏 | 审批分级减负 + 服务时限 |

**会上请拍板：**
1. 本半年只攻坚哪 2–3 个接口。  
2. 每个接口的责任人 / 审批人 / 时限 / 升级找谁（RACI）。  
3. 经营会与争议协调会如何分流（避免变成告状会）。

**会后产物：** 《跨部门关键接口权责清单（下半年版）》。

## 议题 6：调研怎么回应？双休 / 考勤 / 调休是否试点？

**为什么要议：** 调研动员时承诺会认真研究。休息与考勤是最高频体验诉求之一；若不回应，会直接伤害“建言有用”的组织信任，也会影响人才吸引与工作日产出。

**建议讨论方向（逐项表态：做 / 试点 / 暂缓+理由）：**
1. **全员通报**：是否 2 周内公布调研结论与公司态度（采纳 / 研究中 / 暂缓及理由）。  
2. **休息制度**：维持单双休 / 弹性双休试点（有事在岗、无事真休）/ 逐步双休——选一。  
3. **调休规则**：出差遇双休、驻外补偿、到期前提醒、法定假与月休关系——改哪些。  
4. **考勤**：楼下定位打卡、错峰、弹性上下班——先改哪一项降低早高峰摩擦。  
5. **评估**：若试点，范围、周期、用什么指标评估（产出、加班、离职意向等）。

**会上请拍板：**
- 通报时间与口径；试点事项清单；责任部门（人力 / 行政 / 总经办）。

**会后产物：** 《调研回应通报稿》+《休息与考勤决议纪要》。

## 收束口径

六题连起来，就是一套下半年经营对齐：

> **赢法说清，战场收住，订单选准，交付管住，协同打通，人心留住。**

讨论不求面面俱到，但每题都要有方向、有人、有时点。
