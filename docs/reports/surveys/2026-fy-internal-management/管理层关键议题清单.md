# 2026财年内部管理调研 · 管理层关键议题清单  
（部门长联席讨论版）

## 会议定位

这不是“员工意见宣读会”，也不是各部门诉苦会。  
这是一次**部门长联席经营对齐会**：以员工调研为输入，以公司已明确的经营主线为底座，共同回答——

> **下半年，实荣把有限的管理带宽、售前资源、交付产能，押在哪里？各部门如何同向发力？**

### 公司已有经营底座（讨论起点，不必推倒重来）

| 层级 | 已明确口径 | 来源 |
|------|------------|------|
| 年度四大核心任务 | 签约目标；国家级专精特新“小巨人”；钢结构/机电资质升级；引入国际投资及建厂（待大型战略项目后） | 管理层双周经营汇报固定结构 |
| 经营两条主线 | **支持业务成交、促进项目执行** | 董事长汇报版定调 |
| 打单机制（已启动） | 客户需求澄清会 → 方案评审会 → 项目分级管控；报价沟通会；531核心客户 | 温总领导下，6月起推进 |
| 执行机制（已启动） | 启动会 / 双周执行会 / 专题会；计划运营督办；延误挂钩项目组织奖金 | 计划运营月报与双周简报 |
| 标准化方法 | “总体设计、分步实施、不求完美、急用先行”；管理制度 + SOP；约50项待固化 | 经营汇报第三节 |

### 调研补充了什么（为何还要开这次会）

机制已经搭了“架子”，但员工侧与经营数据同时提示：

1. **成单质量仍低**（方案成单率不足10%量级）——澄清会/分级有了，资源仍可能被低质询盘稀释。  
2. **交付存在产能与协同天花板**——多项目并行下设计/加工/发货系统性延误，已在例会提出“月度发货体量匹配”问题。  
3. **战略叙事与现场感受有落差**——对外讲智慧储运/EPC/小巨人，对内仍担心“什么都做不精、集成商缺定价权”。  
4. **组织从个人驱动走向体系驱动尚未完成**——跨部门接口、权责、保障服务导向，成为规模化瓶颈。  
5. **建言若无回应，将透支下一次管理参与**——这是组织信任问题，也是经营问题。

## 一、七大必议议题总览（建议联席会顺序）

| 序 | 议题（讨论命题） | 格局定位 | 主要发言部门 | 建议时长 |
|----|------------------|----------|--------------|----------|
| 1 | 下半年我们到底靠什么增长？ | 战略取舍 | 经营层、业务、品牌、研发 | 40–50 分钟 |
| 2 | **公司的核心竞争力到底是什么？** | 竞争本质 | 经营层、业务、技术、研发、工程、品牌 | 45–60 分钟 |
| 3 | 如何把“询盘热闹”变成“成单质量”？ | 打单质量 | 业务、技术、总经办、品牌 | 40–50 分钟 |
| 4 | 交付能力的天花板在哪里，怎么破？ | 履约与产能 | 计划运营、工程、成本合约、技术、物流 | 40–50 分钟 |
| 5 | 长期壁垒如何加固：EPC 做深还是制造补强？ | 能力路径 | 经营层、研发、成本合约、财务 | 35–45 分钟 |
| 6 | 标准化与组织协同：急用先行抓哪几条？ | 体系能力 | 总经办、计划运营、各部门长 | 30–35 分钟 |
| 7 | 组织动能与人才：规模化靠什么扛住？ | 组织保障 | 人力、总经办、各部门长 | 30–35 分钟 |

**联席讨论规则建议**
- 每个议题先由牵头部门用 3 分钟陈述“现状与矛盾”，再圆桌发言，最后经营层拍板或明确“谁在何时出方案再决”。  
- 发言要对准**公司目标与跨部门接口**，少谈部门内部琐事。  
- 每个议题结束必须留下：**决议 / 试点 / 暂缓（附理由）+ 责任部门 + 时间点**。

## 二、七大议题正文

### 议题 1：下半年我们到底靠什么增长？  
（赛道 · 客户 · 产品叙事 · 与四大任务对齐）

#### 为什么拿到联席会上讨论
公司对外已有主导产品表述（如港口/物流枢纽万吨级粮食筒仓智能储运等），经营上又在推 531 核心客户、缅甸等战略项目；但调研中员工普遍感到行业铺得宽、口径不一，担心“什么都能做、什么都不精”。  
**这不是品牌文案问题，而是下半年资源投向问题：售前、技术、品牌、研发同时只能深耕有限战场。**

#### 联席会上要达成的共识
1. **主航道行业**定 2–3 个（建议在水泥建材、粮食储运、港口散货、矿产/能源中取舍）。  
2. **战略客户逻辑**是否坚持“客户大于项目”，531 与铁三角资源是否优先于散单。  
3. **第二增长曲线**只启动 1 条验证（改造运维 / 工业散料延伸 / 技术服务等），写清投入上限与退出标准。  
4. **与四大任务的关系说清楚**：小巨人、资质、投资建厂，分别服务哪条增长叙事，避免“任务归任务、业务归业务”。

#### 各部门在讨论中的角色
| 部门 | 请准备回答 |
|------|------------|
| 业务部 | 过去半年真正赚钱、可复制的行业/客户类型是什么？哪些单在消耗团队却难成？ |
| 技术/研发 | 哪个行业我们有差异化方案与案例厚度？哪里只是“能做”？ |
| 品牌 | 对外口径能否收敛成一句主叙事？展会/社媒资源跟哪条赛道绑定？ |
| 经营层 | 主航道与机会型的资源比例（如 70/30）是否拍板？ |

#### 讨论焦点（供主持人控场）
- 若继续广覆盖，成单率与交付口碑是否会被继续稀释？  
- 第二曲线若人人都想做，是否等于没有曲线？  
- “智慧储运 / EPC”是营销口号，还是下半年产品与交付标准？

#### 会后应形成
《下半年增长地图一页纸》：主航道 / 战略客户 / 第二曲线试点 / 与四大任务的挂钩关系。

### 议题 2：公司的核心竞争力到底是什么？  
（先统一“我们凭什么赢”，再谈打单、交付与路径）

#### 为什么必须单独立题、而且要部门长一起辩
调研里“核心竞争力”作答率高达约 79%，说明大家关心；但答案并不统一——有人说 EPC 整合，有人说技术工艺，有人说履约口碑，有人说人才组织，有人说制造产能与定价权。  
经营汇报对外又同时出现多种表述：智慧储运系统、专精特新、资质升级、战略客户、建厂可能……  

**若部门长对“我们到底靠什么赢单、赢复购、赢溢价”没有共识，后面的赛道、打单、交付、建厂讨论都会各说各话。**  
本题要达成的不是漂亮定义，而是：**当下真实竞争力是什么、客户愿意为什么付钱、下半年重点加固哪 1–2 项。**

#### 先把调研中的竞争力图谱摊开（供对照，不是投票结果）

| 竞争力维度 | 员工侧典型表述 | 今天有多真？需联席判断 | 若不加固的后果 |
|------------|----------------|------------------------|----------------|
| A. EPC/系统整合交付 | 方案—供应链—施工—调试—售后一体化；交钥匙 | 是不是客户感知最强的差异点？ | 被当成设备商比价 |
| B. 细分行业专业深度 | 懂物料特性、工艺痛点、特殊工况（水泥/粮/港/矿） | 有没有形成可复制的行业解决方案？ | 继续“什么都能做、什么都不精” |
| C. 履约与交付口碑 | 海外圈子小，口碑即订单；按时高质量履约 | 当前延误/返工是否在消耗这块资产？ | 再多品牌投放也难转化 |
| D. 技术与产品差异化 | 智能监测、防腐/气密/出料、绿色低碳、专利/标准 | 是可售卖能力，还是宣传标签？ | 只能拼价格与关系 |
| E. 供应链与制造掌控 | 自有/绑定产能、样品可参观、交期成本可控 | 是否已构成短期短板？ | 长期缺定价权 |
| F. 人才与组织能力 | “技术可被追赶，组织能力才是护城河” | 个人英雄多，还是体系作战强？ | 规模一大就失速 |
| G. 品牌与客户资产 | 标杆项目、531/铁三角、全球认知 | 客户资产在公司还是在个人？ | 市场投入难沉淀 |

#### 联席会上要达成的共识（请逐条拍板）
1. **一句话定义**：用不超过 40 字写清“实荣的核心竞争力是……”——业务、技术、工程、品牌必须能共同对外说。  
2. **主竞争力 + 支撑竞争力**：主项只定 1 个（建议在 A/B/C 中选），支撑项不超过 2 个；其余列为“保持”或“暂不主打”。  
3. **真实与目标分开**：哪些是**今天已经能拿去赢单的能力**，哪些是**2026–2027 要建成的能力**（避免把愿望写成现状）。  
4. **客户价值验证**：新客户首单、老客户复购，分别更认我们的哪一项？有没有项目证据？  
5. **禁止口径**：明确哪些话下半年不再对外主打（如尚无样品却强调制造实力、尚无稳定交付却强调交钥匙无忧等）。  
6. **资源含义**：主竞争力确定后，下半年技术研发、标杆项目选择、品牌案例、考核激励如何倾斜。

#### 可选定位方案（便于当场收敛）

| 方案 | 一句话定位 | 适合条件 | 主要加码动作 |
|------|------------|----------|--------------|
| 方案甲 | **大宗散料智慧储运 EPC 综合交付能力** | 客户买的是系统与履约，而非单台设备 | 强化深化设计、计划总控、标杆履约、售后本地化 |
| 方案乙 | **重点行业工艺+仓储系统专家能力** | 已在 1–2 个行业有厚案例与工艺 know-how | 行业解决方案包、标准方案库、铁三角行业化 |
| 方案丙 | **可信赖的海外工程履约品牌** | 海外口碑已能带来转介绍，交付稳定是命门 | 交付能力上限管理、质量闸门、项目经理责权利 |
| 方案丁 | **技术差异化产品+系统集成** | 已有可演示/可专利/可单独计价的技术模块 | 产品化 1–2 个标签，打单话术与报价清单绑定 |
| 方案戊 | **制造可控的仓储装备商+工程商** | 已具备或决心补齐产能绑定，客户强依赖交期与参观 | 供应商战略绑定或产能试点，样品与标准仓型 |

> 推荐讨论路径：先选甲/乙/丙作为“主定位”，再决定丁/戊是“同步加码”还是“条件成熟后再上”（与议题 5 路径选择衔接）。

#### 各部门在讨论中的角色
| 部门 | 请准备回答（务必具体到项目/客户） |
|------|------------------------------------|
| 业务 | 近一年赢单与丢单，客户口头上最常提的理由是什么？我们被拿去和谁比？ |
| 技术/研发 | 哪些能力竞争对手短期抄不走？哪些其实大家都能做？ |
| 工程/计划运营 | 履约口碑目前是资产还是负债？最伤口碑的三类问题是什么？ |
| 成本合约 | 成本与交期上，我们相对同类集成商的优劣势？ |
| 品牌 | 对外正在主打的三句话，与一线赢单理由是否一致？ |
| 经营层 | 愿意用考核与资源，真正押哪一项为主竞争力？ |

#### 讨论焦点（主持人控场）
- 核心竞争力是“组合拳”可以，但若没有主项，资源必然分散。  
- 宣传中的“智能、低碳、EPC”若未产品化，会不会反过来伤害专业感？  
- 组织能力算不算核心竞争力？若算，下半年要体现在哪条制度与考核上？  
- 与议题 1 的关系：赛道是“在哪打仗”，竞争力是“靠什么打赢”——两题结论必须互相咬合。

#### 会后应形成
1. 《公司核心竞争力定义卡》（一句话主定位 + 2 项支撑 + 禁止口径）  
2. 《下半年竞争力加固清单》（每项：动作、责任部门、里程碑、衡量标准）  
3. 同步给品牌/方案封面/展会话术的统一表述（总经办督办替换旧口径）

### 议题 3：如何把“询盘热闹”变成“成单质量”？  
（在已有澄清会、评审会、分级机制上再进一步）

#### 为什么拿到联席会上讨论
打单机制并非空白：需求澄清会、方案评审会、项目分级、报价沟通会已在温总推动下运行；公海二次开发、展会获客也在放量（询盘可阶段性冲高）。  
但经营诊断与调研同时指向：**方案成单率偏低、无效方案消耗技术、需求未澄清即提资、报价策略与复盘不足。**  
联席会要讨论的不是“要不要机制”，而是——**机制如何长牙齿，让重点项目吃饱、低质线索快速终止。**

#### 联席会上要达成的共识
1. 项目/线索三级分类的**响应标准**是否对公司各部门强制有效（战略/重点/一般分别谁上、做到什么深度）。  
2. 提资前置清单缺项时，技术是否有权退回；业务是否接受“先澄清再设计”。  
3. 报价是否试点分档（高/中/低配置）与竞对信息沉淀。  
4. 成单/丢单复盘是否进入月度经营会固定议程，由谁交材料。  
5. 品牌展会线索如何进入同一套分级漏斗，避免“热闹进、无效出”。

#### 各部门在讨论中的角色
| 部门 | 请准备回答 |
|------|------------|
| 业务 | 分级标准若落地，对考核与行为最大的冲击是什么？能否执行？ |
| 技术 | 当前并行方案量、被低质询盘占用的比例大概多少？退回机制需要什么支持？ |
| 总经办 | 澄清会/评审会频次与质量如何？如何从“开会”变成“筛选与决策”？ |
| 成本合约/报价 | 报价审核与分档能否支撑？缺什么岗位或数据？ |
| 品牌 | 展会/社媒线索的合格率与移交质量如何提升？ |

#### 讨论焦点
- 分级若只写在纸上、系统无必填、考核不挂钩，会不会退回“广撒网”？  
- 技术资源保护，是不是成单率提升的前提条件？  
- “客户大于项目”如何落到具体的资源倾斜规则？

#### 会后应形成
《打单质量提升决议》：分级响应表 + 提资退回规则 + 经营会复盘议程 + 责任部门与上线日。  
（对齐现有闭环：需求上报任务管家 → 澄清会 → 方案 → 评审会 → 报价审核 → 回写系统）

### 议题 4：交付能力的天花板在哪里，怎么破？  
（计划总控 · 质量供应链 · 多项目并行产能）

#### 为什么拿到联席会上讨论
执行侧并非没管理：全景计划、双周执行会、专题会、延误纳入项目组织奖金已在跑；巴基斯坦、斯里兰卡、越南等项目风险也在董事长汇报中置顶。  
真正的战略问题是例会已点出的：

> **公司项目交付能力与月度发货体量是否匹配？多项目并行是否导致设计/加工/发货系统性延误？**

员工调研则把断链说得更细：深化设计—采购—质检—发货—现场。  
联席会要站在公司层面决定：**下半年交付是“继续靠人盯”，还是“总控有权、质量有闸、产能有数”。**

#### 联席会上要达成的共识
1. 计划运营对后端节点是否具备**可考核的总控权**（不只督办清单）。  
2. 交底 / 变更纪要 / 完工复盘是否列为公司强制动作。  
3. 供应商分级、发货前质检（尤其焊接与细节）能否成为拦货闸门。  
4. 下半年在施与临签并行下，**月度可承载的设计产出、加工吨位、发货批次**是否有经营层认可的能力上限；超限如何排产/拒单/外协。  
5. 安全与重大质量是否一票否决；现场问题是否明确“先止损复产、后复盘定责”。

#### 各部门在讨论中的角色
| 部门 | 请准备回答 |
|------|------------|
| 计划运营 | 当前总控最大卡点是权限、信息，还是考核牙齿？ |
| 技术 | 打单任务与执行深化设计如何抢资源？需要怎样的排产规则？ |
| 成本合约 | 供应商质量与交期能否分级挂钩份额？短板厂家如何处理？ |
| 工程 | 现场质量、劳务、发货节奏最需要公司层给什么支持？ |
| 物流 | 发货与现场脱节的典型原因与裁决机制建议？ |
| 业务 | 若交付触顶，临签与承诺交期如何与后端会签？ |

#### 讨论焦点
- 没有能力上限意识，签约越多是否风险越大？  
- 组织奖金考核已启动，下一步缺的是“标准”还是“执行一致性”？  
- 交付口碑是否应上升为与签约并列的经营指标？

#### 会后应形成
《下半年交付能力决议》：总控权限、三项强制动作、供应商/质检闸门、产能上限与排产原则。

### 议题 5：长期壁垒如何加固：EPC 做深还是制造补强？  
（EPC 做深 · 制造补强 · 小巨人/资质 · 技术产品化）

#### 为什么拿到联席会上讨论
在议题 2 明确“核心竞争力是什么”之后，本议题解决“怎么把竞争力加固到位”。四大任务里已有“小巨人、资质升级、投资建厂”；调研里又有“纯集成商缺定价权、希望自建或绑定产能”的呼声。  
如果部门长各说各话——研发推专利、业务推签约、供应链想控厂、财务忧重资产——公司会在“轻资产整合”与“重资产制造”之间摇摆。  
**联席会要把 12–24 个月的主路径说清楚，并与四大任务对齐，而不是平行空转。**

#### 先统一概念（避免会上各说各话）
- **EPC 做深：** 强化方案/深化设计、供应链整合、全球交付与履约口碑，把“交钥匙能力”做成客户愿意付溢价的理由。  
- **制造补强：** 通过自建、租赁产线、参股或战略协议，把关键仓型/关键件的成本、交期、质量更多握在自己手里，缓解“参观无样品、议价被动”。  
- 二者不是口号对立，但**资源上必须有主次**。

#### 联席会上要达成的共识
1. 未来 12–24 个月，主路径是：① EPC+履约为主；② 制造补强为主；③ 双轮并行（须同时批预算与团队）。  
2. 若涉产能：是否只允许“单品类 + 绑定方式（协议/参股/租赁）+ 投资上限 + 退出条件”，今年是否不做全面自建重资产工厂。  
3. 小巨人、省级技术中心、资质人员引进，如何服务主路径（专利/设备/人员是加分项，也是能力项）。  
4. 选出 1–2 个必须产品化的技术标签（智能监测、特殊物料工艺、防腐气密出料等），半年内形成可售卖方案包。

#### 各部门在讨论中的角色
| 部门 | 请准备回答 |
|------|------------|
| 经营层 | 主路径选择与风险偏好 |
| 研发/技术 | 哪些能力已接近“可产品化”？哪些还停留在项目经验？ |
| 成本合约 | 绑定核心供应商 vs 自建，账怎么算、风险怎么控？ |
| 财务 | 重资产/参股的现金流与核算约束 |
| 法务 | 专利、资质、合资绑定的法律节奏 |
| 业务 | 客户是否真的因“有产线/有样品”而提高转化？ |

#### 讨论焦点
- 建厂任务是“条件成熟后启动”，还是下半年就要立项试点？  
- 没有拳头产品，出海是否会更依赖价格战？  
- 专精特新与资质，是证书工程，还是竞争力工程？

#### 会后应形成
《竞争力主路径决议》+（如需要）《制造/供应链试点立项卡》+ 与小巨人/资质任务的责任对接表。

### 议题 6：标准化与组织协同——急用先行抓哪几条？  
（把“50 项流程”变成下半年能打赢的几场关键仗）

#### 为什么拿到联席会上讨论
公司标准化方法论已经明确：**总体设计、分步实施、不求完美、急用先行**；并区分管理制度（权责与跨部门规则）与 SOP（作业步骤）。盘点中有约 50 项待固化。  
调研与一线摩擦则显示：业务—技术提资、物资—质检、发货—现场、保障审批等接口仍在消耗组织能量；会议易变长、变“告状”。  
**联席会不要重新发明体系，而要决定：下半年“急用先行”的优先序，以及跨部门接口的权责牙齿。**

#### 联席会上要达成的共识
1. 从待固化清单中，选出下半年 **5–8 条急用流程**（建议优先服务打单质量与交付总控）。  
2. 本半年只攻坚 **2–3 个跨部门关键接口**，每个接口明确 RACI、时限、升级路径。  
3. 明确原则：影响交付的问题先形成处置方案，复盘追责放后；经营会与争议协调会分流。  
4. 保障部门定位：在合规前提下，更多“业务支持 + 风险保障”（报销、票务、盖章等减负是否纳入急用清单）。

#### 建议优先讨论的接口（可勾选）
| 接口 | 为何急用 | 牵头建议 |
|------|----------|----------|
| 业务 ↔ 技术提资 | 直接决定成单质量与技术产能 | 总经办 + 业务 + 技术 |
| 设计 ↔ 采购 ↔ 质检 | 直接决定延误与现场质量 | 计划运营 + 成本合约 + 技术 |
| 发货 ↔ 现场 | 直接决定窝工/积压与口碑 | 计划运营 + 物流 + 工程 |
| 财务/行政审批 ↔ 一线 | 直接决定出差、回款、节奏效率 | 财务 + 行政 + 总经办 |

#### 各部门在讨论中的角色
各部门长需回答：本部门最拖累公司目标的一条跨部门流程是什么？愿意为哪条接口让渡什么权限？

#### 会后应形成
《下半年急用流程优先序》+《2–3 个关键接口权责清单》+ 总协调人（总经办/计划运营）与季度复盘点。

### 议题 7：组织动能与人才——规模化靠什么扛住？  
（体系驱动 · 人才结构 · 调研闭环 · 员工体验）

#### 为什么拿到联席会上讨论
签约在增长、项目在并行、小巨人与资质要人、国际化要复合人才——组织若仍主要靠少数骨干个人能力，天花板会先于市场到来。  
调研高频提到：带教弱、绩效与部门负责人脱节、协同文化不足；同时双休/考勤/调休等体验问题情绪明确。  
**在部门长联席会上，员工体验不应等同于福利诉苦，而应上升为：人才吸引力、人均产出、管理可信度——即组织能否支撑下半年经营目标。**

#### 联席会上要达成的共识
1. 下半年关键岗位人才缺口清单（建造师/高职称、业务带头人、项目经理、复合型售前等）与引进/培养优先级。  
2. 绩效与项目组织奖金是否真正经部门负责人与计划节点闭环（能者多得是否可执行）。  
3. 新员工带教、业务铁三角能力（业务懂基础技术）是否作为组织动作，而非部门自选。  
4. 调研回应：2 周内是否全员通报；休息/考勤/调休哪些做试点、哪些暂缓并说明理由。  
5. 优秀建言奖励与季度进展表，是否纳入总经办督办，形成“建言—决策—反馈”闭环。

#### 各部门在讨论中的角色
| 部门 | 请准备回答 |
|------|------------|
| 人力 | 缺口、引进难度、带教与绩效机制方案 |
| 各部门长 | 本部门支撑公司目标最缺什么样的人？绩效哪些指标该砍、该硬？ |
| 总经办 | 调研通报与决议督办机制 |
| 经营层 | 对休息制度试点的底线与评估标准 |

#### 讨论焦点
- 没有组织信任，流程再多是否也会空转？  
- 人才问题是“招不到”，还是“养不住、用不好、协同不动”？  
- 员工体验改善，如何与人均产出、离职风险一起评估？

#### 会后应形成
《下半年组织与人才要点决议》+《调研回应通报口径》+ 试点事项清单（含评估指标）。

## 五、收束口径（可作会议开场/结尾）

下半年部门长联席，建议钉死一句经营总纲：

> **战场收得住，赢法说得清，订单选得准，交付扛得住，壁垒看得远，体系跟得上，人心留得住。**

对应七个议题：增长取舍、核心竞争力、成单质量、交付能力、壁垒路径、标准化协同、组织人才。  
员工调研证明一线有经营感觉；管理层会议与计划运营体系证明公司已有制度底座。  
**这次会的价值，是把“已有架子”和“一线真相”合成下半年可执行的共同策略。**
