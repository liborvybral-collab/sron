# 2026财年内部管理调研 · 管理层关键议题清单

**背景：** 第一阶段员工意见搜集已完成（有效答卷 58 份）。第二阶段需围绕关键议题开展管理层讨论，明确下半年经营策略方向与关键点。

**使用方式：** 建议管理层会优先讨论【必议】议题并形成结论；【选议】议题可并入专题会或责成部门方案后再决。每个议题给出建议讨论问题与可选决策方向，便于当场拍板或明确下一步责任人。

## 二、必议议题（建议本轮管理层会完成）

### 议题 1：赛道聚焦与第二增长曲线取舍

**员工侧信号**
- 主流认同：大宗散料智慧储运 / EPC 系统解决方案。
- 高频行业：水泥建材、粮食、港口散货、矿产/煤炭/能源。
- 分歧：继续拓宽 vs 2–3 个行业做深；担心“什么都能做、什么都不精”。
- 第二曲线呼声：旧仓改造/运维/智能化、工业散料一体化延伸、特殊物料（化肥/木屑等）、技术服务输出。

**建议讨论问题**
1. 下半年主航道行业清单是哪 2–3 个？哪些行业只做机会型、不主动铺资源？
2. 第二增长曲线先验证哪一条（建议优先“存量改造+运维”）？投入上限与退出标准是什么？
3. 对外品牌口径是否统一为“智慧储运系统解决方案/EPC”，并停止发散表述？

**可选决策方向**
- A. 明确《聚焦行业清单 + 试验清单》一页纸，按 70% / 30% 配置资源  
- B. 维持现状广覆盖，仅加强项目筛选（风险：继续稀释专业口碑）

**建议结论产物：** 《下半年赛道与第二曲线决议》一页纸（含责任人）

---

### 议题 2：打单资源聚焦——线索/项目分级与成单率

**员工侧信号**
- 询盘多、有效商机少；比价型线索消耗技术资源。
- 方案时间被压缩、需求未澄清就提任务；报价一刀切、缺分档与竞对情报。
- 公海跟进不彻底、过早放弃；业务与技术协同不足。

**建议讨论问题**
1. 是否正式落地线索/项目三级分类（战略/重点/一般）及差异化响应标准？
2. 询盘提资是否强制前置检查清单（物料、流程、范围、品牌要求）？不达标可否退回？
3. 技术资源如何保护：重点项目深做，低价值线索标准化快响？
4. 成单/丢单复盘是否纳入月度经营会硬环节？

**可选决策方向**
- A. 30–45 天内上线分级 SOP + 提资前置 + 月度复盘  
- B. 仅口头强调“抓重点”，不改流程（风险：问题复现）

**建议结论产物：** 《项目分级与打单协同制度》要点 + 落地时间表

---

### 议题 3：项目执行总控——计划运营与交付口碑

**员工侧信号**
- 典型断链：深化设计滞后 → 采购/质检不同步 → 发货与现场脱节 → 赶工返工。
- 呼声：计划运营全景节点一张图；供应商分级；劳务队伍制度化；质量纳入项目经理硬考核；先止损后追责；安全一票否决。

**建议讨论问题**
1. 计划运营部是否明确为后端执行“总控”角色？节点目标是否对后端部门具约束力？
2. 项目启动交底、变更纪要、完工复盘是否强制？
3. 供应商分级与末位淘汰、质检标准（尤其焊接/细节）是否本半年落地？
4. 交付口碑（客户满意度/返工率/节点达成）是否进入项目组织奖金？

**可选决策方向**
- A. 强化计划运营总控 + 复盘制度 + 供应商/质检硬约束  
- B. 维持部门垂直管理，仅加强协调会（风险：断链难解）

**建议结论产物：** 《下半年交付提升三项硬措施》（总控、复盘、供应商/质量）

---

### 议题 4：核心竞争力路径——EPC 深化 vs 自有产能

**员工侧信号**
- 共识：竞争力是组合能力（EPC + 细分专业 + 履约口碑 + 技术差异化 + 组织能力）。
- 焦虑：无拳头产品、参观无样品、纯集成商缺定价权。
- 建议：深化设计壁垒、本地化服务、供应链绑定；亦有自研/参股/租赁产线等产能路径提议。

**建议讨论问题**
1. 近 12–24 个月，公司更押注哪条主路径：做深 EPC/方案交付，还是补齐战略品类产能？
2. 若碰产能，是否只允许“小步试点”（单品类、租赁/参股、设退出门槛），禁止全面重资产化？
3. 哪些技术标签必须从口号变成可售卖能力（智能监测、防腐/气密/出料、绿色低碳等）？

**可选决策方向**
- A. 主路径明确为“EPC+履约口碑+深化设计”，产能为专题论证后试点  
- B. 同步推进自有产能专项（需配套资金、团队、质量体系决议）

**建议结论产物：** 《核心竞争力主路径决议》+（如需要）《产能试点立项门槛》

### 议题 5：员工体验与组织信任——双休 / 考勤 / 调休

**员工侧信号**
- 休息制度是最高频员工体验议题之一（约 38%）；周六产出低、法定假叠加不合理、驻外调休不对等。
- 考勤：电梯拥堵 + WiFi 打卡焦虑；报销/审批繁琐叠加负面体感。
- 组织心理：集中反馈若无正面回应，下次无人认真写。

**建议讨论问题**
1. 下半年是否试点弹性双休或优化单双休/调休规则？试点范围与评估周期？
2. 考勤能否改为楼下定位/错峰等低成本改善？
3. 调研结果何时、以何种口径向全员通报（采纳 / 研究中 / 暂缓及理由）？

**可选决策方向**
- A. 2 周内通报 + 30 天内出台休息/考勤试点方案  
- B. 仅内部研究、暂不对外（风险：信任透支）

**建议结论产物：** 《调研回应通报稿》+《休息与考勤优化试点决议》

---

### 议题 6：跨部门协同与权责机制

**员工侧信号**
- 部门内氛围尚可，跨部门紧张、各自为战、信息差、推诿、会议低效。
- 组织正从“个人英雄”走向“体系作战”，但机制未跟上。
- 诉求：权责清晰、少无效会议、先解决问题再划责、铁三角真正落地。

**建议讨论问题**
1. 下半年最痛的 2–3 个跨部门接口是哪些（如业务—技术提资、物资—质检、设计—采购—现场）？
2. 是否按接口出台权责清单 + 升级路径（谁协调、谁拍板、时限）？
3. 会议机制如何改：经营决策会 vs 告状会，如何分流？

**可选决策方向**
- A. 选定 2–3 个接口做权责清单与 SLA，季度复盘  
- B. 靠文化倡导与团建改善（风险：协同问题难结构性解决）

**建议结论产物：** 《跨部门关键接口权责清单（下半年版）》

## 三、选议议题（可专题会或部门方案后决策）

### 议题 7：品牌资产沉淀
- 讨论点：重点项目是否强制素材采集；案例库谁建谁维护；品牌是否纳入项目/业务协同考核。
- 目标：把交付转化为可复用传播资产，服务获客而非“品牌部单点发力”。

### 议题 8：AI 与数字化落地节奏
- 讨论点：P0 场景（知识库、翻译/标书、办公账号）是否 60–90 天试点；预算与数据安全红线；是否先上财务/业务数据底座再谈预测型 AI。
- 目标：避免概念空转，形成 2–3 个可见提效场景。

### 议题 9：管理保障减负（财务 / 行政 / 法务审计尺度）
- 讨论点：报销弹性规则（如小额容差）、票务审批流优化、月报时效、财务系统上线节奏；法务审计“保护锁非枷锁”的尺度原则。
- 目标：降事务摩擦，保障部门转向业务支持。

### 议题 10：人才梯队、激励与调研闭环
- 讨论点：新员工带教与师徒激励；绩效是否部门负责人真正经手；提成透明度与周期；优秀建言奖励与季度进展表。
- 目标：支撑规模化，并闭环“建言—回应—改进”。

## 六、一句话建议

下半年经营策略讨论，建议抓住一条主线：

**“赛道做深 + 打单做准 + 交付做稳”**，同步用 **“员工体验回应 + 协同机制”** 守住组织信任与执行力；AI、品牌、保障减负作为支撑项，不与主线抢决策带宽。
