# 实荣2026财年内部管理调研分析报告

## 一、调研概览与核心结论

本次《2026财年内部管理调研》共回收 **有效答卷 58 份**，10 道开放题覆盖品牌、赛道、竞争力、打单、执行、AI、管理保障、效率状态、文化氛围及开放建议。答卷平均填写 **6.6 题**，平均有效字数约 **926 字**，其中深度建言（>800 字）23 份，说明员工参与意愿总体较高，且不乏系统性、可落地的经营建议。

### 管理层应优先关注的五条判断

1. **战略共识已形成，但执行抓手不足。** 多数同事认同“散料储运 EPC / 智慧储运系统解决方案”方向，也反复提出应聚焦水泥、粮食、港口、矿产等优势行业；同时普遍担心“什么都能做、什么都不精”，要求把标杆项目、拳头产品和口碑做成可复制能力。
2. **打单与执行是最大经营痛点闭环。** 前端询盘多、成单率低、线索分级不足；后端深化设计周期被挤压、采购/质检/发货协同弱、现场质量与劳务不稳定。两端共同指向：项目分级、资源聚焦、计划总控、复盘沉淀。
3. **组织正在从“个人英雄”走向“体系作战”，但协同文化跟不上。** 多题出现“各自为战、信息差、推诿、会议低效、权责不清”。这不是单点流程问题，而是规模化阶段的组织能力短板。
4. **员工体验议题高度集中且情绪明确。** 双休/调休、考勤打卡（电梯拥堵）、报销与审批简化，是跨层级最高频诉求。若长期不回应，将直接影响参与调研的可信度与后续建言质量。
5. **AI 已具备落地土壤，缺的是工具、场景与机制。** 员工不是在讨论概念，而是明确提出知识库、翻译/标书、客户调研、风险预警、办公助手、账号与培训。建议按“试点场景 + 付费工具 + 人工终审 + 数据安全”快速推进。

## 四、分题分析

### Q1 品牌宣传（作答率 81%）

**现状共识**
- 最好的宣传是标杆项目与口碑，不是空泛口号。
- 品牌部“有枪缺子弹”：项目/技术/业务素材供给不足，视频与现场感内容偏少。
- 对外口径需统一；夸大宣传会被专业客户识破，反而伤信任。

**高频建议**
1. 建立全公司素材供给机制：重点项目强制采集航拍、节点、客户评价；专项经费可支持现场拍摄。
2. 把交付转化为传播：按行业/仓型做深度案例（数据、对比、痛点解决）。
3. 展会全周期运营（会前预热—会中短视频—会后成果传播），并打通线索沉淀。
4. 海外平台（LinkedIn / YouTube / Facebook）与雇主品牌同步建设。
5. 抖音等账号要有专人负责与内容标准，避免“应付式更新”。

**管理启示：** 品牌不是品牌部单点工作，应纳入项目交付与业务协同KPI的一部分。

---

### Q2 产品与赛道定位（作答率 67%）

**主流定位表述**
- 从“筒仓设备/工程项目”升级为 **大宗散料智慧储运系统解决方案 / EPC**。
- 重点行业反复出现：**水泥建材、粮食储运、港口散货、矿产/煤炭/能源**。
- 第二增长曲线较集中的方向：
  - 旧仓改造、备件与运维、智能化升级（毛利稳、客户粘性强）
  - 工业散料向破碎/烘干/输送/装卸一体化延伸
  - 化工储罐、环保/特殊物料（木屑颗粒、化肥等）差异化场景
  - 技术服务/图纸包输出（轻资产）

**主要分歧**
- 一部分建议“继续拓宽钢结构相关业务”；另一部分强烈反对“什么都做”，主张 2–3 个行业做深。
- 对“是否自建工厂/绑定制造产能”存在明显呼声，认为纯集成商长期缺定价权。

**管理启示：** 赛道聚焦决策应尽快明确并对外统一表达；第二曲线建议优先验证“存量改造+运维”，投入小、见效快。

---

### Q3 公司核心竞争力（作答率 79%）

**共识画像：组合竞争力，而非单一产品**
1. **EPC 全流程整合能力**（方案—供应链—交付—售后）
2. **细分领域专业深度**（物料特性、工艺、特殊工况）
3. **履约与交付口碑**（海外圈子小，口碑即获客）
4. **技术研发与差异化**（智能监测、防腐/气密/出料、绿色低碳）
5. **人才与组织能力**（“技术可被追赶，组织能力才是护城河”）

**尖锐但有价值的判断**
- 无拳头产品、参观无样品、过度依赖价格与关系，出海已是红海。
- 深化设计能力、本地化服务、供应链绑定，是集成商现实可建壁垒。
- 部分同事提出自研抱箍筒仓、参股/租赁产线等具体产能路径，值得专项评估。

---

### Q4 项目打单（作答率 66%）

**问题画像**
- 询盘多、有效商机少；比价型线索消耗技术资源。
- 线索跟进不彻底（渠道单一、过早放弃、公海管理弱）。
- 方案时间被严重压缩，质量与细节不足，影响专业形象与中标率。
- 报价偏高或一刀切；缺少分档报价与竞对价格情报。
- 业务与技术协同不足：需求未澄清就提任务；会议多、真正打磨少。

**建设性建议（已可试点）**
| 动作 | 说明 |
|------|------|
| 线索/项目分级 | 战略/重点/一般，不同响应深度与资源投入 |
| 询盘前置审核 | 业务先澄清物料、流程、范围、品牌要求，再提技术任务 |
| 方案库+报价模板 | 成熟筒仓场景标准化，减少重复劳动 |
| 分档报价 | 高/中/低配置对应不同预算客户 |
| 复盘闭环 | 成单与丢单均复盘，沉淀竞对与失败原因 |
| 大客户铁三角 | 总/组长/技术对战略客户定期项目会 |

---

### Q5 项目执行（作答率 76%）

**问题链条（高度一致）**
深化设计滞后或不深 → 采购节奏乱/供应商质量不稳 → 质检与物资信息不对称 → 发货与现场脱节 → 现场赶工返工、劳务质量波动 → 口碑与成本双损。

**高频改进方向**
1. 强化计划运营总控（全景节点一张图，后端部门对齐节点而非各自为战）。
2. 项目启动交底 + 变更书面纪要 + 完工复盘沉淀“避坑指引”。
3. 供应商分级考核与末位淘汰；质检标准化（尤其焊接与细节）。
4. 发货服从现场进度，避免窝工或积压。
5. 劳务队伍筛选与管理制度化；现场质量纳入项目经理硬考核。
6. 问题处理优先“止损复产”，复盘追责放后面；同时安全一票否决。

---

### Q6 AI 应用（作答率 66%）

员工建议已相当具体，可直接形成试点清单：

| 优先级 | 场景 | 解决痛点 |
|--------|------|----------|
| P0 | 企业知识库（图纸/方案/制度/案例检索+多语） | 经验在个人脑子里，海外响应慢 |
| P0 | 办公提效（翻译、标书初稿、纪要、排版） | 重复劳动占比高 |
| P1 | 客户/商机调研与公海二次开发 | 线索浪费、信息搜集慢 |
| P1 | 项目风险预警与健康度看板 | 进度/采购/物流偏差滞后发现 |
| P2 | 设计辅助、合规比对、视觉质检 | 专业岗提效与质量兜底 |

**落地原则（员工原话高度一致）**
- 买账号/额度 + 培训 + 场景试点；AI 辅助、人工终审。
- 核心工艺参数与商业秘密不上公网。
- 先打通数据底座，再谈预测类 AI，否则只是“高级搜索”。

### Q7 管理保障（作答率 45%）

意见相对集中，不代表问题少，而代表接触面窄。分部门看：

1. **总经办：** 专门点名论述较少（3 份明确提及），但方向清晰——
   - 有同事将总经办与人资、行政、财务、法务、审计并列，定位为统筹协调与风险保障部门，主张整体从“审批管控”转向“业务支持 + 风险保障”；
   - 具体改进意见包括：**减少不必要会议**；
   - 亦有正面评价：跨部门协调、SOP 流程梳理“很接近优秀大型企业表现”，并建议增加标杆分享与荣誉表彰会；
   - 另有答卷涉及盖章/总经理审批权限分级（合作协议、保密协议等非关键合同不必层层到总经理；高于一定金额及大型项目再走总经理审批），侧面反映审批效率诉求。

2. **财务：** 意见最多、也最具体，集中在“报销体验、经营信息时效、数字化支撑、资金与风险协同”四方面——
   - **报销过严过繁、耗时长：** 有人直言“几张票折腾 1–2 小时”；海外汇率波动、打车停车费/过路费无票但支付金额可核对、纸质发票裁剪粘贴规范等细节要求过细，出差本身辛苦，不应在报销环节再消耗大量精力。建议在保证真实性前提下保留弹性，例如金额 3000 元以内、发票误差 5% 以内，由报销人说明或补票，无需整单重提审批。
   - **票据合规与公司成本冲突：** 举例出国手机漫游——自行买流量更省却因无票不能报，只能选更贵但能开票方案；建议对“更省钱但无票”与“更贵但有票”建立特殊审批机制，以公司整体利益判断。出差、参展、公司软件付费等明确业务支出，尽量减少个人垫付。
   - **粘贴单与表单体验：** 建议粘贴单改为 A4，现有尺寸看似省纸，实际打印裁剪错误多、反而更浪费；报销表单中的项目目录需实时更新。
   - **月报及时性：** 建议每月 10 日前出具月度财务报表及说明，便于领导掌握经营情况，也便于审计跟进。
   - **财务系统上线：** 个人年度报销仍靠 Excel 统计，亟需线上财务系统打通日常报销与经营管理数字化。
   - **其他经营协同：** 工资发放时清晰列明项目提成计算方式、总利润、提成基数与发放比例；项目尾款回款定期通报督促责任人（供应商已出现抬价规避尾款风险）；中信保投保目前单人端口操作、金额较高，建议强化审核；财务与审计定期清点兆泰仓库通用库存（如镀锌钢管）；正面评价方面，有人肯定财务风险把控严谨，并建议每月/季度开财务分析会。

3. **人力：** 关注点从“事务办理”转向“人才体系与绩效机制”——
   - **新员工带教弱：** 入职后工作多靠自己摸索，无人带帮较突出；CRM 使用、邮箱抄送等基础规则也不清晰。建议恢复入职后带新员工到各部门介绍，并建立公司级 + 部门级系统培训，缩短上手周期。
   - **绩效需部门负责人真正参与：** 有人认为考核内容、打分、发多少工资部门负责人未深度参与；建议纸质或线上考核都必须经部门负责人，才能“能者上、庸者下，能者多得”。另有意见提出绩效指标应减少冗余，坚持“抓重点、看结果”，剔除细碎低价值指标；主要职能部门可对员工综合能力与表现做年度考核，作为调薪依据。
   - **人才画像与梯队：** 国际化阶段对复合型人才需求升高，建议建立关键岗位梯队（新业务、技术倾斜资源），培养懂技术、懂业务、懂国际市场的人才，避免过度依赖少数核心人员；经理及以上人才引进宜偏重大公司背景、专业资格与多年对口管理经验；重要岗位补强“选育用留”人才画像培训。
   - **职称与发展通道：** 希望公司在评职称上提供帮助；同步完善培训体系与晋升通道，让员工看到长期发展机会。
   - **制度宣贯：** 建议人力资源对全员管理制度做线下统一宣贯；调休/假期类制度执行前应事先告知说明。另有个别尖锐评价认为“人资、行政懒散”，虽属少数，但提示服务响应体感需关注。

4. **行政：** 问题更贴近日常办事效率与规则沟通——
   - **差旅票务审批过长导致机票涨价甚至无票：** 出差审批与票务购买审批流高度重叠（主管→负责人→公司领导），机票价格实时性强，等审批完成再买往往已涨价或无票、打乱行程。建议出差仍走原审批至公司领导；票务购买改为行政先审、部门负责人终审，缩短购票窗口。
   - **订票体验：** 尤其国外机票，价格差距不大时尽量减少转机次数。
   - **调休规则沟通不足：** 调休到期“一刀切”消除、未提前通知，影响工作动力；项目调休属个人假期，行政/人事若执行制度应事先告知；日常调休跨年至次年 7 月底作废，有人希望延长。差旅补助起止时点条款也偏笼统，建议明确国内/境外补助核算节点。
   - **其他：** 请假可增加“2 小时”选项；办公环境方面有人肯定行政认真负责，并建议增加月度生日集体活动。另有答卷反映办公网络/WiFi/VPN、会议室电脑配置等保障条件影响效率，属行政与信息化协同范畴。

5. **法务/审计：** 核心张力是“控风险”与“保业务推进”的尺度——
   - **总原则：** 合同、供应商管理与审计制度具有双面性；若条款与处罚一律按公司单方极致安全执行，可能合作推不动、损失更大（如供应商处罚机制被形容为“双刃剑”）。法务、审计应是风险防控的“保护锁”，不应成为限制业务发展的“枷锁”；在合法合规与重大风险可控前提下，保留合理协商空间。
   - **审计规范化与透明：** 建议建立清晰、公开的审计规范标准；项目成本预算表制度尽快落地，并在总经办、财务、审计、人事备案，便于审计评价；项目完工总结复盘资料提交工程部经理时同步提交审计。
   - **协同减负：** 签约量上升后，纸质合同再分别移交财务、法务造成重复整理，建议以成本合约部归档为主，财务/法务优先用电子版或借阅，减少纸质留存份数。
   - **劳动合规提醒：** 有答卷指出加班一律调休、法定假加班报酬等问题，认为法务应对相关制度风险保持敏感（该观点情绪较强，宜作为合规复核线索，而非单一结论）。

6. **总原则（跨部门共识）：** 保障部门应从“审批管控”更多转向“业务支持 + 风险保障”；主动参与打单与执行、常态化对接一线项目与海外痛点，避免管理要求与现场业务脱节；在制度正确、风险可控前提下，最大限度为业务和员工创造便利。

### Q8 工作效率与状态（作答率 76%）

**第一梯队诉求（强烈、跨岗位）**
- **双休 / 单双休与调休规则**：周六产出低、法定假叠加不合理、驻外调休不对等。
- **考勤打卡**：28 楼电梯拥堵 + 必须连 WiFi，早高峰焦虑明显；建议楼下定位打卡/错峰/弹性。
- **流程减负**：报销、出差计划/报告、多系统重复录入（施工日志等）。

**第二梯队**
- 任务穿插导致工作碎片化（技术部尤为突出：打单与执行抢时间）。
- 跨部门信息差、会议过长且“告状化”。
- 办公网络/VPN/电脑配置影响效率。

**管理启示：** 员工体验议题若不正式回应（哪怕分阶段试点），将削弱“建言有用”的组织信任。

### Q9 团队氛围与文化建设（作答率 64%）

**双面画像**
- 部门内部：多数评价务实、融洽、互助。
- 公司跨部门：协同紧张、压抑感、各自为战、联谊不足。

**活动建议共识**
- 少形式、少纯爬山/纯聚餐；多兴趣运动、亲子游、跨部门联谊、经验分享。
- 团建不要变成变相开会；文化要服务经营（协作、客户、创新），不是口号。

### Q10 开放题（作答率 36%）

开放题基本是对前述议题的强化：
- 再次呼吁双休与福利竞争力（司龄假/生日假等）。
- 晋升通道、提成周期与激励公平。
- 执行力与优胜劣汰、让肯干的人不吃亏。
- 会议效率、过度管理、资料统一归档平台。
- **关键组织心理：** “集中反馈要有正面回应，否则下次没人认真写。”

## 七、建议奖励与后续机制

调研动员中已承诺“好建议认真研究并给予奖励”。建议：

## 八、结语

本次调研最有价值的信号，不是“大家有意见”，而是 **员工已经在用经营者视角思考公司**：赛道如何取舍、口碑如何积累、打单如何聚焦、交付如何总控、AI 如何降本增效、组织如何从个人驱动升级为体系驱动。

公司若能在未来一个季度内完成三件事——**公开回应、打通打单执行闭环、改善最集中的员工体验痛点**——将把这次调研从“意见征集”升级为“管理升级的真实起点”。
