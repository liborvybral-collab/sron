# 路演/展会PPT联系方式调整与商机归属分析

## 一、议题与结论先行

展会/路演收尾页（Thank you页）目前对外公开的是**公司级入口**：郑州座机、温总个人手机/WhatsApp、`info@sronsilo.com`、官网与总部地址。业务员提出：公司座机经常打不通，建议改成业务员手机。同步计划把座机划转客户管理部，保障接通。

这不是换一个号码的事。号码印在公司对外材料上，等于规定了**商机第一下落到谁手里**，也等于规定了**跟进权、统计权、离职后客户还在不在公司**。

**建议决策：**

1. **公司对外主材料（路演母版PPT、官网、样本册、展台主视觉）不改印业务员个人手机。** 公司花钱买来的入口，必须先落到公司，再按规则分配。
2. **座机划转客户管理部是对的，而且应该立刻做。** 业务员抱怨的是真实损耗，不能用“归属敏感”把接通问题拖着不解决。
3. **海外客户真正走的是WhatsApp，不是郑州座机。** 只改座机管不住海外进线。对外页应补**公司主体WhatsApp**，由客户管理部值守，不能继续默认“打不通就找业务员私人号”。
4. **业务员的个人号用在“当面开发之后”，不用在“公司主材料上”。** 展会现场谈过的客户，允许留个人名片/WhatsApp，但必须当日入库；入库后保护其跟进权。
5. **先写清商机归属规则，再改版PPT。** 没有规则就换号，等于用技术动作改权限。

一句话：**商机所有权在公司，跟进权按规则授予业务员；接通问题用客户管理部值班解决，不用个人号替换公司入口。**

## 二、这页PPT现在到底在承担什么角色

对照路演收尾页，五条联系方式的角色并不一样：

| 对外信息 | 名义归属 | 实际功能 | 当前风险 |
|----------|----------|----------|----------|
| 座机 `+86-371-63253880` | 公司 | 国内/正式来电入口 | 经常无人接，公司入口失效 |
| 手机/WhatsApp `+86-17719833319` | 温总 | 海外即时沟通 + 董事长背书 | 战略通道被当成客服热线；忙则等于没人接 |
| `info@sronsilo.com` | 对外是公司邮，对内落到温总 | 书面询盘入口 | 若只进董事长邮箱，响应和管理都不可复制 |
| 官网 / Facebook | 公司品牌 | 可追踪、可交接的公共入口 | 与PPT号码不在同一套分发规则里 |
| 总部地址 | 公司 | 主体背书 | 无争议 |

这页的定位应是**公司对外总机**，不是某位业务员的名片，也不是董事长的私人值班表。海外B2B大单客户看这页，读到的信号是：“我在和SRON谈，必要时能找到温总。” 这是品牌资产，不宜改成“我在和某位业务员的私人WhatsApp谈”。

公司近几个月展会、论坛密集（越南水泥展、澳门展、加纳水泥展、链博会，以及温总出席的基础设施论坛、APEC、上合、链博会论坛）。路演母版会在多个场合反复使用。印上去的号码，不是一次展会的权宜之计，是**长期公共入口**。

## 三、业务员诉求：表层合理，底层是权限

### 1. 表层理由成立

座机经常打不通，客户打一次打不通，很少打第二次。海外客户更不会反复拨郑州区号。公司已把“客户首次回复时效”“展会管控动作完整度”列为销售过程指标，入口无人接，这两项指标在源头就空转。

所以：**接通必须先解决，不能用“号码敏感”把问题搁置。**

### 2. 底层诉求是“谁先接到，谁就拥有”

业务员建议“改成我的手机”，真正改的不是接通率，而是：

- 第一声问候从公司总机，变成业务员私人微信/WhatsApp；
- 询盘是否进入公司统计、是否按组分配，变成业务员个人决定；
- 客户以后找谁，不再经过客户管理部。

这和公司已经在跑的体系是对着干的：询盘按业务组分配、公海由客户管理部二次开发、展会动作要可核验。双周经营汇报里，询盘是按组记账的（1–6组、俄语组）。入口一旦私人化，账就记不全。

### 3. 公司已经付过“私人号断档”的学费

乌兹别克斯坦磷矿粉项目质保金跟进中，出现过“原联系人离职，暂无人联系”。客户只认个人号时，人走号走、聊天记录走，公司 Continuity 为零。路演母版若印业务员私人号，等于把这个风险写进公司主视觉。

## 四、真正要拆开的三件事

不要把三件事捆成一个“换号”动作。

| 层级 | 问题 | 应掌握在谁手里 | 常见错法 |
|------|------|----------------|----------|
| 入口所有权 | 客户第一眼看到谁的号 | 公司（客户管理部值守） | 印业务员私人号 |
| 跟进权 | 谁被授权继续谈 | 按区域/语种/是否已有负责人分配给业务员 | “谁先加到微信就是谁的” |
| 业绩归属 | 谁拿提成、记谁的询盘 | 分配后的负责人；当面开发且入库的，保护开发人 | 不入库却主张私有 |

**权限原则：公司渠道进线 = 公司资产，按规则分配；业务员当面谈下来的 = 绩效应得，但必须入库。不能用换号码代替定规则。**

分配时应先查“是不是已有负责人”，再按区域/语种/行业落到现有业务组。争议由客户管理部会同业务部负责人裁定，不采用“先接到算谁的”。

这与公海逻辑一致：跟进不达标或离职未交接，回收到公司，而不是跟着私人号走。

## 五、三种改法

### 方案A：对外主材料只留公司入口，座机划转客户管理部（建议）

- 路演母版、官网、样本册、展台主视觉：座机 + 公司邮箱 + 官网；海外即时沟通用**公司主体WhatsApp**（客户管理部值守）。
- 业务员个人号出现在：现场名片、谈完后的一对一跟进、展会《一对一跟进表》。
- 当面开发的客户，当日入库后保护跟进权，避免“公司入口”把业务员现场谈下来的人再抽走。

**利：** 入口可交接、可统计、可考核；离职不断档；与询盘分组、公海、展会制度一致。  
**弊：** 客户管理部必须真正接得住；海外若没有公司WhatsApp，业务员仍会私下改PPT。  
**适用：** 公司主材料、多场复用的路演母版。

### 方案B：公司总机 + 当场联系人（仅限单场展会物料，有条件）

某一场展会的一页纸/桌牌，可加一行“本场现场联系人 + 公司配发号或当场业务负责人”，**不替换**母版上的公司总机。

**利：** 给现场一个即时出口，减少业务员偷改母版。  
**弊：** 若把“现场联系人”写进总母版，仍会变成个人入口。  
**适用：** 单场物料；每场结束作废；品牌运营部控版。

### 方案C：主材料改印业务员手机（不建议）

**利：** 当场接通率可能上升，业务员积极性高。  
**弊：**  
- 公司入口变成私人资产，离职即断；  
- 询盘体外循环，分组账、公海、过程指标失真；  
- 谁的号上母版，谁截流所有场合的询盘，内部抢单；  
- 海外大单客户感知从“找SRON”降成“找某个销售”；  
- 印上去容易，收回来等于承认公司入口曾经被个人占用，很难做。

**不适用**于路演母版和长期对外材料。

## 六、座机划转客户管理部：划转什么，才算管住

“划转到客户管理部”如果只是改缴费主体或行政挂靠，座机照样没人接。要划的是**接通责任 + 登记责任 + 分配责任**。

客户管理部已经在做公海二次开发，并处在“从商机获取到交付”的主干链上，适合做公司总机，不适合再把总机交给业务员兼职。

### 1. 值守

- 工作时间固定值班，禁止“顺便听听”。
- 非工作时间：转到公司值班手机，或留言后下一工作日首小时回拨。
- 海外时区：不能只靠郑州座机；公司WhatsApp必须有人看。

### 2. 进线必做

1. 接听/回复；  
2. 当场登记（来源、国家、行业、项目线索、是否已有负责人）；  
3. 按规则分配到业务组；  
4. 把公司侧联系人告知客户，避免客户只记住某一个私人号。

### 3. 考核（建议与现有过程指标对齐）

| 指标 | 建议口径 | 责任部门 |
|------|----------|----------|
| 工作时间接通率 | 目标≥90% | 客户管理部 |
| 进线登记完整率 | 接通后当日100%入库 | 客户管理部 |
| 分配时效 | 登记后30分钟内到人（争议单除外） | 客户管理部 |
| 首次有效回复时效 | 沿用业务部过程指标 | 业务部（分配后） |
| 展会线索入库率 | 与“展会管控动作完整度”合并 | 业务部 + 客户管理部 |

### 4. 公司WhatsApp（比座机更关键）

非洲、东南亚、中东客户习惯WhatsApp。现页把WhatsApp绑在温总私人号上，效果是：打不通座机的人，全部堆到董事长聊天列表。温总忙，业务员就会要求“改成我的号”——这是结构逼出来的，不是态度问题。

**建议：** 申请公司主体WhatsApp（公司卡、公司账号、客户管理部值守），作为对外主材料上的即时沟通号。温总个人号从“默认总机”改为“重大客户/需董事长出面时的升级通道”，由客户管理部或业务负责人申请转介，而不是印在每一页路演尾页上。

`info@sronsilo.com` 同步改为客户管理部值守的共享邮箱，温总可保留抄送或每周摘要，避免每封询盘都要董事长本人点开。

## 七、给业务员的出路（否则他们会改私下版本）

只禁止私人号上母版、不给合法出口，业务员会做两套PPT。必须把激励对齐：

1. **现场谈过的，入库即保护。** 展会/路演当场交换的联系方式，当日录入后，跟进权归开发人，不因“进线是公司总机”再抽走。  
2. **公司进线按规则分，不分给“谁改了PPT”。** 官网、座机、公司邮箱、公司WhatsApp、母版二维码，一律公司先登记再分配。  
3. **不入库视为放弃主张。** 超过时限未登记，可改分或进公海。  
4. **组长辅导奖、展会管控指标与入库绑定。** 已经在做组长陪同澄清会、展会复盘，把“线索是否在公司系统里”算进展会效果，而不是只数加了多少私人WhatsApp。

这样业务员得到的是**可被公司承认的跟进权**，而不是**不可被公司看见的私人通讯录**。前者能发奖金，后者只在离职时变成公司的窟窿。

## 八、建议落地顺序

1. **先定规则（总经办牵头，业务部、客户管理部、品牌运营部会签）**  
   写一页《对外联系方式与商机归属规则》：公司入口清单、分配顺序、现场开发保护、未入库后果、离职交接。不先换号。
2. **再把座机做成真总机（客户管理部）**  
   值班表、话术、登记字段、分配时限、接通率。对外可先不改页，对内先接得通，把业务员的正当抱怨消掉。
3. **再补公司WhatsApp和共享邮箱（客户管理部 + 品牌运营部）**  
   这是海外入口的正解，也是把温总私人号从客服位上换下来的前提。
4. **最后改路演母版（品牌运营部控版）**  
   母版只留公司入口；单场物料如需现场联系人，走方案B，一场一版，展后作废。  
   与正在定稿的《展会管理制度》《展会管理作业指导书》一并写入：禁止擅自替换母版号码。
5. **过程指标验收**  
   接通率、登记率、分配时效、展会线索入库率，进双周询盘回顾，避免“划转了但没人接”变成第二次形式主义。

## 九、请温总拍板的三件事

1. **路演/展会母版是否禁止印业务员个人手机？**  
   建议：禁止。个人号只用于现场开发后的一对一跟进。
2. **座机是否正式交客户管理部值守，并按接通率/登记率/分配时效考核？**  
   建议：是，且立即执行，不等PPT改版。
3. **对外主材料上的WhatsApp、info邮箱，是否从温总个人通道改为公司主体通道？**  
   建议：改。温总个人号保留为升级通道，不再当默认总机。此项涉及董事长对外形象，需温总本人定，不建议业务部门自行替换。

## 十、一句话答复业务员（可用口径）

座机打不通，是公司入口失职，马上由客户管理部值守、考核接通，并补公司WhatsApp，保证客户找得到SRON。  
公司路演和展会主材料上的号码，是公司入口，不能改成个人手机——否则商机在系统外、人走客户走。  
你在现场谈下来的客户，只要当日入库，跟进权归你，公司按这个记询盘、记奖金。  
**要的是“接得通、分得清、跟得住”，不是“谁的手机印在PPT上”。**
