## 命名规范

`YYYY-MM-{部门名}月报.md`，例如 `2026-06-国际业务部月报.md`

## 使用说明

编写月报时：
1. 提供部门经营数据（表格、Excel 导出或关键数字）
2. AI 读取部门模板和历史月报
3. 分析数据并撰写，先确认后保存

**请先上传各部门 1-2 期历史月报，作为分析参照。**

## 与经营汇报的关系

编写管理层双周会经营汇报时，需综合三个部门当月月报。
