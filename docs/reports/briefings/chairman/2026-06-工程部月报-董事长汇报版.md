# 2026年6月工程部月报（董事长汇报版）

温总，工程部6月份的月报，请审阅。共涉及4个在施项目，各项目成本与进度情况汇报如下：

一、埃及8×9000T卷边仓项目（项目经理：袁纪斌）
【进度】截至6月底，累计形象进度约97.3%，累计完成产值134.42万元，当月实际完成率达94.1%。8座卷边仓已全部完成安装（7号仓于6月8日完成，8号仓于6月15日落仓），主体安装阶段已收尾。受前期斋月减半上班、开斋节放假及当地工人数量不足等因素累积影响，整体进度仍滞后于原计划节点（指导施工），当前项目剩余交付时间约33天，需加快设备指导安装与收尾交付。
【成本】截至6月底，累计应支出成本155.36万元，占累计实际产值的115.6%，成本超支情况持续（指导施工）；其中卷边仓安装预算116.15万元已累计支出133.80万元，超预算约15.2%，收尾阶段需重点盯紧成本管控。

二、MAK2×7000T水泥仓系统项目——蒙古国（项目经理：李亚超）
【进度】截至6月底，累计形象进度约50.8%，累计完成产值308.33万元，当月完成产值62.81万元，当月实际完成率约52.8%。土建部分累计形象进度约73.3%，当月完成产值30.50万元；钢板仓及钢结构部分已启动，累计形象进度约15.3%，当月完成产值28.00万元。受业主混凝土及钢筋等材料供应延误、大风降雨停工等因素影响，较计划仍有滞后，剩余交付时间约93天。后续土建收尾与钢结构安装交叉并行，工期压力仍然较大，需重点关注业主材料供应节点。
【成本】截至6月底，累计应支出成本289.86万元，占累计实际产值的94.0%，成本整体可控，暂无超支风险；钢结构安装已开始发生成本，后续需持续跟踪安装阶段成本执行。

三、巴基斯坦SECMC铁路装车站项目（项目经理：曹明刚）
【进度】截至6月底，土建部分累计形象进度约74%，累计完成产值805.86万元，较计划完成产值1089万元滞后约26%。装车楼部分工期延误约55天（较5月底约40天进一步扩大）。主要原因：前期斋月影响及业主第二笔里程碑款项审核迟延的滞后效应仍在，6月份OK公司人数维持在约230人，仍不满足计划赶工人数要求，人员增加缓慢、工作效率偏低，装车楼重要部位推进偏慢。虽持续两班倒赶工，进度差距尚未有效收窄。截至6月30日BPB02基础混凝土已浇筑，预计装车楼主体结构推至8月15日全部结束，相关支架基础等预计7月底完成；钢结构机电安装尚未启动，剩余交付时间约150天，进度风险仍需高度重视。
【成本】截至6月底，土建部分累计应支出成本563.8万元，占累计实际产值的70.0%，较5月份（82.8%）继续改善，成本整体在预算内运行，但需持续关注施工效率与赶工投入，避免后期赶工推高成本。

四、淮北临涣焦化除尘灰回配工程项目（项目经理：崔继龙）
【进度】截至6月底，累计形象进度约75.4%，累计完成产值35.60万元，当月完成产值19.97万元。土建部分已全部完结；钢结构设备安装累计形象进度约60%，当月完成产值7.33万元。筒仓安装已于6月10日完成（此前因货运及进场问题延误约6天）；受非标材料（预计7月2日到货）及电控桥架（6月23日到货）发货滞后约15天影响，设备安装实际于6月30日启动，进度有所放缓。剩余交付时间约18天，需抓紧设备与电控安装调试，确保按期收尾。
【成本】截至6月底，累计应支出成本32.64万元，占累计完成产值的91.7%。因材料滞后导致安装放缓、管理费投入相对刚性，成本占比有所抬升，但仍整体可控。

综合来看：三个海外项目工期压力依然突出。埃及项目主体仓体已安装完成，但累计成本产值比仍达115.6%，超支风险最为突出（指导安装），收尾阶段需严控追加成本；巴基斯坦项目工期滞后幅度继续扩大至约55天，虽持续赶工，人员仍不足且钢结构尚未启动，按期完工不确定性大，需重点跟进；蒙古项目钢结构已启动，但受业主材料供应及天气影响，土建与安装交叉期工期较紧，需加强现场协调。国内淮北项目筒仓已完成，当前受材料到货滞后影响进入设备安装收尾冲刺，成本进度总体仍在可控范围，需盯紧交付节点。
