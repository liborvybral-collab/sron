# 2026年7月工程部月报（董事长汇报版）

温总，工程部7月份的月报，请审阅。共涉及4个在施项目，各项目成本与进度情况汇报如下：

一、MAK2×7000T水泥仓系统项目——蒙古国（项目经理：李亚超）
【进度】截至7月底，累计形象进度约70.2%，累计完成产值425.69万元，当月完成产值117.36万元，当月实际完成率约92.9%。土建部分累计形象进度约90%，累计完成产值295.20万元；钢板仓及钢结构机电部分累计形象进度约38.1%，累计完成产值69.72万元。2#筒仓结构已于7月24日完成，火车坑地下室结构、防水及回填分别于7月18日、7月25日、7月31日完成；汽车衡基础预计8月10日完成。仓内填坡因业主地泵未到场暂未开工，预计8月3日、8月5日启动；钢结构预计8月20日完成（原计划7月5日），工艺管道、电气顺延至8月中下旬。受业主材料供应及风雨停工影响，较计划仍有滞后，剩余交付时间约62天，土建收尾与安装交叉并行，工期压力仍然较大。
【成本】截至7月底，累计应支出成本327.05万元，占累计实际产值的76.8%，较6月底（94.0%）明显回落，成本整体可控；钢结构机电当月支出占当月产值约128%，安装阶段成本需持续盯紧。

二、巴基斯坦SECMC铁路装车站项目（项目经理：曹明刚）
【进度】截至7月底，累计形象进度约49.6%，累计完成产值925.65万元（均为土建）；土建部分累计形象进度约85%，当月完成产值119.79万元，当月实际完成率约49.5%（当月计划242万元）。土建相对计划已超期约46天（表内剩余交付时间-46天）。主要原因：前期斋月及业主第二笔里程碑审核迟延的滞后效应仍在；7月份因OK公司资金问题，装车楼剩余钢筋进场延迟约12天，人数与效率仍不达赶工要求。截至7月31日BPB01基础筏板钢筋绑扎约80%，预计8月10日浇筑完成；装车楼主体结构预计推至8月31日全部结束（6月汇报为8月15日，进一步顺延）；相关小基础预计8月15日完成，T1–T27开挖预计8月10日完成。钢结构机电安装仍未启动，预计装车楼钢结构8月20日才开装；项目合计剩余交付时间约119天，按期完工不确定性大，进度风险仍需高度重视。我方已申请拆分土建第三笔里程碑付款以缓解OK公司资金压力，业主原则同意但支付时间未定。
【成本】截至7月底，土建部分累计应支出成本777万元，占累计实际产值的83.9%，较6月底（70.0%）明显抬升；当月支出213.2万元，占当月产值约178%，赶工投入已推高成本，需重点关注后续赶工成本与支付节点联动。

三、北方稀土（包头）料仓及计量输送系统项目（项目经理：李鲲鹏）
【进度】截至7月底，累计形象进度约45%，累计完成产值22.05万元（=当月产值），当月实际完成率约72.6%（当月计划产值30.38万元）。项目实际开工7月1日，计划完工2026年8月5日，剩余交付时间约19天。安装准备按期完成；现场下料预制因降雨及暗访停工约3.5天、分包人员偏少，预计拖至8月5日；支撑柱受总包预埋件及人员不足影响；锥体环梁已制作完成，预计约8月2日安装；仓体吊装预计8月5日起；配套设备管道预计8月6日起装。对照现场实际排期，按8月5日节点收尾压力较大，存在滑点风险，需督促增人并盯紧吊装启动。
【成本】截至7月底，累计应支出成本15.13万元，占累计实际产值的68.6%，占预算49万元约30.9%，成本整体可控；“其他”分项成本/产值偏高，需结合收尾投入持续跟踪。

四、淮北临涣焦化除尘灰回配工程项目（项目经理：崔继龙）
【进度】截至7月底，累计形象进度约97.6%，累计完成产值46.06万元，当月完成产值17.46万元，当月实际完成率约93.9%。土建部分已全部完结；钢结构机电安装累计形象进度约95%。受非标材料（7月2日到货）及电控桥架等发货滞后约15天影响，设备、电控、供水管、非标件整体于7月24日完成，现已进入调试阶段，调试预计8月3日完成，计划8月6日验收。相对原计划完工日（7月3日）已超期约13天，需盯紧调试与验收闭环。
【成本】截至7月底，累计应支出成本35.03万元，占累计完成产值的76.1%，较6月底（91.7%）回落，整体可控；管理费累计支出占预算约90.2%，材料滞后阶段管理费刚性投入仍偏高。楼梯踏步板更换、供水管属合同新增，劳务费用存在增补，收尾阶段需一并确认。

综合来看：海外两个在施项目仍是重点。巴基斯坦项目土建已超计划约46天，装车楼主体节点由8月15日进一步推至8月31日，钢结构尚未启动，且当月赶工已明显推高成本，需同步跟进里程碑拆分付款与现场增效；蒙古项目形象进度由约50.8%提升至约70.2%，成本产值比回落至76.8%，当月完成率约92.9%，态势好于上月，但仍受业主材料/地泵供应制约，安装交叉期需继续盯紧。国内方面，淮北项目已进入调试验收冲刺，节点需按8月6日验收闭环；新开包头北方稀土项目进度约45%，对照8月5日计划完工存在滑点风险，需督促分包增人并确保吊装按期启动。
