# 2026年7月工程部月报（董事长汇报版）

温总，工程部7月份的月报，请审阅。共涉及4个在施项目，各项目成本与进度情况汇报如下：

一、MAK2×7000T水泥仓系统项目——蒙古国（项目经理：李亚超）
【进度】截至7月底，累计形象进度约70.2%，累计完成产值425.69万元，当月完成产值117.36万元，当月实际完成率约92.9%。土建部分累计形象进度约90%，累计完成产值295.20万元；钢板仓及钢结构机电部分累计形象进度约38.1%，累计完成产值69.72万元。1#、2#筒仓卷边仓结构已分别于7月1日、7月25日完成，火车坑地下室结构、防水及回填分别于7月18日、7月25日、7月31日完成。钢结构已于7月15日实际开工，斗提机塔架、火车坑罩棚等安装持续推进。据8月上旬周报：1#仓内填坡已启动模板安装，但业主地泵至8月9日仍未进场，混凝土填坡浇筑仍受制约；2#汽车衡基础钢筋绑扎推进中；安装设备进场日期未定，设备安装无法展开。剩余交付时间约62天（按7月底月报表），土建收尾与钢结构交叉并行，工期压力仍然较大。
【成本】截至7月底，累计应支出成本327.05万元，占累计实际产值的76.8%，较6月底（94.0%）明显回落，成本整体可控；钢结构机电当月支出占当月产值约128%，安装阶段成本需持续盯紧。

二、巴基斯坦SECMC铁路装车站项目（项目经理：曹明刚）
【进度】截至7月底，累计形象进度约49.6%，累计完成产值925.65万元（均为土建）；土建部分累计形象进度约85%，当月完成产值119.79万元，当月实际完成率约49.5%（当月计划242万元）。土建相对计划已超期约46天（表内剩余交付时间-46天）。主要原因：前期斋月及业主第二笔里程碑审核迟延的滞后效应仍在；7月份因OK公司资金问题，装车楼剩余钢筋进场延迟约12天，人数与效率仍不达赶工要求。截至7月31日BPB01基础筏板钢筋绑扎约80%，预计8月10日浇筑完成；装车楼主体结构预计推至8月31日全部结束（6月汇报为8月15日，进一步顺延）；相关小基础预计8月15日完成，T1–T27开挖预计8月10日完成。钢结构机电安装仍未启动，预计装车楼钢结构8月20日才开装；项目合计剩余交付时间约119天，按期完工不确定性大，进度风险仍需高度重视。我方已申请拆分土建第三笔里程碑付款以缓解OK公司资金压力，业主原则同意但支付时间未定。
【成本】截至7月底，土建部分累计应支出成本777万元，占累计实际产值的83.9%，较6月底（70.0%）明显抬升；当月支出213.2万元，占当月产值约178%，赶工投入已推高成本，需重点关注后续赶工成本与支付节点联动。

三、北方稀土（包头）料仓及计量输送系统项目（项目经理：李鲲鹏）
【进度】截至7月底，累计形象进度约45%，累计完成产值22.05万元（=当月产值），当月实际完成率约72.6%（当月计划产值30.38万元）。项目实际开工7月1日；7月期间下料预制受降雨、暗访停工及分包人员偏少影响偏慢。据8月9日周报校正：业主审批开工报告节点为9月1日（不宜按原表8月5日作为最终收尾口径）；截至8月9日，两个锥体拼装及吊装安装、环梁、库顶、悬梯等已完成，支撑钢柱安装约60%、钢梯约40%，罐体拼装焊接推进中；现场人员仍不足（保节点要求不低于17人，实际约13人），已多次下发罚款督促增人。剩余主要工作为钢支撑完善、罐体吊装、设备及电控安装，需继续盯紧人员到位与9月1日节点。
【成本】截至7月底，累计应支出成本15.13万元，占累计实际产值的68.6%，占预算49万元约30.9%，成本整体可控；“其他”分项成本/产值偏高，需结合收尾投入持续跟踪。

四、淮北临涣焦化除尘灰回配工程项目（项目经理：崔继龙）
【进度】截至7月底，累计形象进度约97.6%，累计完成产值46.06万元，当月完成产值17.46万元，当月实际完成率约93.9%。土建部分已全部完结；钢结构机电安装累计形象进度约95%。受非标材料（7月2日到货）及电控桥架等发货滞后约15天影响，设备、电控、供水管、非标件整体于7月24日完成并进入调试。据8月9日周报：远程调试已完成，已于8月6日按甲方要求验收通过并达到设备出料正常；现进入验收消缺、资料完善与陪产收尾（踏步板更换、临边护栏、场地道路恢复等）。相对原计划完工日（7月3日）曾超期约13天，主体施工目标已闭环。
【成本】截至7月底，累计应支出成本35.03万元，占累计完成产值的76.1%，较6月底（91.7%）回落，整体可控；管理费累计支出占预算约90.2%，材料滞后阶段管理费刚性投入仍偏高。楼梯踏步板更换、供水管属合同新增，劳务费用存在增补，收尾消缺阶段需一并确认。

综合来看：海外两个在施项目仍是重点。巴基斯坦项目土建已超计划约46天，装车楼主体节点由8月15日进一步推至8月31日，钢结构尚未启动，且当月赶工已明显推高成本，需同步跟进里程碑拆分付款与现场增效；蒙古项目形象进度由约50.8%提升至约70.2%，成本产值比回落至76.8%，当月完成率约92.9%，钢结构已于7月15日开工并持续推进，但业主地泵未到制约仓内填坡浇筑、安装设备未到制约设备安装，交叉期仍需盯紧。国内方面，淮北项目已于8月6日验收通过，转入消缺与资料收尾；包头北方稀土项目进度节点应按业主审批开工报告的9月1日口径跟踪，当前锥体吊装已完成、罐体拼装推进中，但人员仍不足，需督促分包增人保节点。
