# 2026年5月工程部月报（董事长汇报版）

温总，工程部5月份的月报，请审阅。共涉及4个在施项目，各项目成本与进度情况汇报如下：

一、埃及8×9000T卷边仓项目（项目经理：袁纪斌）
【进度】截至5月底，累计形象进度约85%，累计完成产值117.65万元，当月实际完成率达100%，与计划基本吻合。目前1-6号仓已完成安装，7-8号仓预计6月上旬完成。受斋月减半上班、开斋节放假5天及当地工人数量不足等因素影响，整体进度较原计划主体完工节点滞后约30天（指导施工），当前项目剩余交付时间约51天，需加快收尾推进。
【成本】截至5月底，累计应支出成本134.80万元，占累计实际产值的114.6%，成本超支情况持续（指导施工），需重点关注后续成本管控。

二、MAK2×7000T水泥仓系统项目——蒙古国（项目经理：李亚超）
【进度】截至5月底，累计形象进度约40.5%，累计完成产值245.52万元。因签证问题推迟复工，4月21日实际开工后，土建部分正在持续推进，当月完成产值48.57万元；钢板仓及钢结构部分尚未启动。剩余交付时间约124天，较计划仍有一定滞后，后续工期压力较大，需关注业主混凝土供应及钢结构启动时间节点。
【成本】截至5月底，累计应支出成本226.99万元，占累计实际产值的92.5%，成本整体可控，暂无超支风险。

三、巴基斯坦SECMC铁路装车站项目（项目经理：曹明刚）
【进度】截至5月底，土建部分累计形象进度约62%，累计完成产值675.18万元，较计划完成产值968万元滞后约30%，工期延误约40天。主要原因：斋月影响及业主第二笔里程碑款项审核迟延（历时27天），导致OK公司资金不足，材料机械组织不力。5月9日起已启动两班倒赶工，进场人员增至200人以上，但进度差距尚未有效追回。装车楼筏板预计6月28日全部完成，土建整体预计推至7月下旬，钢结构机电安装尚未启动，剩余交付时间约180天，进度风险仍需高度重视。
【成本】截至5月底，土建部分累计应支出成本558.8万元，占累计实际产值的82.8%，较4月份明显改善，成本整体回归预算内，但需持续关注并推动业主及时放款，避免资金问题再度影响施工节奏。

四、淮北临涣焦化除尘灰回配工程项目（项目经理：崔继龙）
【进度】截至5月底，累计形象进度约47.9%，累计完成产值22.63万元。土建部分已全部完成，钢结构设备安装已于5月中旬启动，当月完成产值11.06万元，进展正常。因钢储罐货运及进场问题延误约6天（预计6月3日到货），筒仓安装预计6月10日完成，剩余交付时间约31天。另需注意，6月为安全月，计划停工30天，需提前统筹安排施工节点，确保7月底如期完工。
【成本】截至5月底，累计应支出成本19.11万元，占累计完成产值的84.5%，成本控制良好，整体运行正常。

综合来看：三个海外项目均存在不同程度的工期滞后，其中埃及项目成本超支风险最为突出（指导安装），累计成本产值比已达114.6%，需重点管控；巴基斯坦项目工期滞后幅度最大，虽已采取赶工措施，但能否按期完工仍存在较大不确定性，需持续跟进；蒙古项目钢结构阶段尚未启动，后续工期较为集中，需提前做好资源部署。国内淮北项目整体运行平稳，成本进度均在受控范围内。
