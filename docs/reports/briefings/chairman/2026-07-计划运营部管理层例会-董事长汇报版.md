# 2026年7月计划运营部管理层例会（董事长汇报版）

温总，结合计划运营部6月项目执行月报及7月13日管理层双周例会简报（期间：6/29–7/12），梳理汇报如下。整体围绕“支持业务成交、促进项目执行”两条主线，先聚焦重点项目，再按职能部门列示重点工作与节点要求。

## 一、重点项目进展与风险

### 1. 巴基斯坦SECMC铁路装车站项目（高风险）
- **现状**：土建持续赶工、SECO已入场；第2批次0705已发货；钢构进度滞后，钢构/机电拟8月初开工动员。
- **月报口径**：土建逾期约50天、采购加工逾期约45天；设计/供货/安装多段中度逾期，存在工期及业主管理风险。
- **关键节点**：土建主体完工 **7月30日**（目标约70%）；非标2/剩余电控设计提交招采 **7月30日**；后续发货批次 **7/20、8/10**。
- **需关注**：电气图纸待业主最终确认；钢构滞后是否拖累8月安装开工。

### 2. 斯里兰卡4×2000吨水泥仓项目（高风险）
- **现状**：第1批次原计划0630发货已延迟（筒仓0706完成）；信用证 **7月30日到期**；业主可能验货、信用证可能延期。
- **月报口径**：设计/制造中度逾期，存在工期罚款风险。
- **关键节点**：业务确定订舱/议付发货款 **7月15日**；第2批次加工完成 **7月25日**（钢结构0725/非标0713/电控0725）；内部盯控节点 **7月15日 / 8月2日**。
- **需关注**：发货与信用证窗口高度咬合，技术部钢构/非标/电控设计延误已纳入项目组织奖金考核。

### 3. 蒙古新2×7000T水泥仓系统项目（进度敏感）
- **现状**：土建/筒仓施工推进中；结构0619已发货，设备拟0715/0720发货（避开那达慕）；业主混凝土等供应仍影响现场。
- **关键节点**：设备发货 **7月15日/7月20日**；筒仓完工 **7月30日**；土建0830、钢构机电0930；卸车坑/门窗/装修补充协议 **7月30日前**。
- **需关注**：进度款催收与业主材料供应，已直接影响现场节奏。

### 4. 阿联酋开心果和杏仁筒仓项目（外部风险高）
- **现状**：业主初步验货后整改，0707整改完成目标；加工完成100%；待整改结果确认后催发货款、安排发货。
- **月报口径**：中东战争影响，业主接货存在风险。
- **关键节点**：整改结果汇报及催款发货安排 **7月20日**；整改结果文件交业务 **7月15日**。

### 5. 菲律宾Davao及Cebu淀粉仓项目（新启动协同）
- **现状**：0702专题会后推进；0706业务/技术/工程赴菲现场勘察；已出新全景进度计划（0703）；国内工人已确定，当地施工合同待签。
- **关键节点**：重新确定工期/增补与施工合同 **7月15日**；宿务4×180T装配仓及配套结构完工 **8月10日**；计划运营推进当地合同 **7月30日**。
- **需关注**：付款时间、设计疑义变更、品牌电机供货周期需与业主尽快钉死。

### 6. 越南QNC 4×6000T卷边仓项目（发货冲刺）

- **关键节点**：批次发货 **7/11、7/15、7/19、7/23**；全部具备发货条件 **7月12日**。

### 7. 埃及在施项目（收尾与待定）

### 8. 淮北临涣焦化除尘灰回配项目（收尾）
- **现状**：发货约98%、施工约94%，货已基本发完（变更除外）；计划0715除变更外工作全部完成。

- **说明**：非标电控设计/设备生产曾延误，目前整体可控，已纳入项目组织奖金考核。

## 三、综合提示（供决策）

1. **工期与罚款风险最紧**：斯里兰卡（信用证7/30到期+发货延误）、巴基斯坦（土建/钢构双线滞后）。
2. **外部不可控因素**：阿联酋战争接货风险；埃及两项目后续指导/调试节奏受业主侧影响；蒙古业主材料供应仍制约现场。
3. **近期必须闭环的合同/商务事项**：菲律宾淀粉仓合同重定、蒙古卸车坑补充协议、阿尔及利亚承包商确定、乌兹别克完税证明与付款、MAK WEST合同签订。
4. **内部能力议题（例会协同事项）**：公司项目交付能力（月度发货体量与产能匹配）需专题讨论，避免多项目并行导致设计/加工/发货节点系统性延误。
