# 2026年7月计划运营部月报（董事长汇报版）

温总，计划运营部7月份月报，请审阅，汇报如下：

一、重点项目（高风险项目4个+中风险项目6个）

巴基斯坦SECMC铁路装车站项目（高风险）
土建逾期约60天、采购加工逾期约55天；设计/供货/土建均为中度逾期；第1–3批次已发（0624/0705/0727），第4批次盯控0815；钢构机电准具备施工；电气图纸业主确认延期至8月2日，剩余电气设计资料8月4日提交招采。存在工期耽误及施工过程业主管理风险。

斯里兰卡4×2000吨水泥仓项目（高风险）
原0630发货未兑现，信用证0730改延期推进中，预计约8月初船期；正与客户沟通FOB发货，提货款催收中。批注提示电控/非标设计严重逾期、钢结构生产逾期；存在发货款风险。

阿联酋开心果和杏仁筒仓项目（高风险）
中东战争影响接货；已发函催付货款并确认发货日期（FOB）；管链机接口等整改曾跟进，提货款沟通催收中；客户接收货风险仍在。

菲律宾Davao及Cebu淀粉仓项目（高风险）
设计、制造均为中度逾期；达沃预付20%已收，0720踏勘后又有变更；施工合同待签，达沃后改造工艺段待业主确认；绞龙供期至10月、品牌电机0903；第1批次0629已发运。业主反复事务多，执行困难、风险大。

蒙古新2×7000T水泥仓系统项目（中风险）
土建计划0831完工，钢构/设备施工约35%、发货约75%；整体收款约35.8%，进度款催收持续；卷仓设备（SM50/SM60）返回与后续维修影响周转。存在供货与施工进度款支付风险。

埃及2×500t水泥仓项目（中风险）
制造中度逾期、进度约95%；钢构设计/业主确认延迟约3个月，计划0818交货验货；中东局势下业主接货存在风险。

埃及2×1万吨水泥仓及输送项目（中风险）
施工验收中度逾期；筒仓施工已交接完成，设备指导安装进行中；指导施工时间过长。

阿尔及利亚颗粒仓和储罐项目（中风险）
储罐保温设计严重滞后，交货暂定推迟至0825；制造基本完成；业务需跟进工期顺延沟通。

埃及8×9000吨水泥卷边仓项目（中风险）
筒仓指导安装已完成；设备指导待再进场；卷仓设备返回及逾期租赁费、指导施工费催收进行中。

乌兹别克碳酸钙筒仓项目（中风险）
客户部分余款0729已付；防雨棚增补钢构按计划加工，盯控0812具备交货条件；存在5%质保扣款风险。
