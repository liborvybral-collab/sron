# 2026年7月计划运营部月报（董事长汇报版）

温总，计划运营部7月份月报，请审阅，汇报如下：

一、重点项目（高风险项目4个+中风险项目6个）

巴基斯坦SECMC铁路装车站项目（高风险）
土建逾期约60天、采购加工逾期约55天；设计/供货/土建均为中度逾期；第1–3批次已发（0624/0705/0727），第4批次计划0815；钢构机电准具备施工；回款多节点催收中；存在工期耽误及施工过程业主管理风险。批注提示非标、其他材料、电控设计逾期。

斯里兰卡4×2000吨水泥仓项目（高风险）
信用证0730改延期推进中，正与客户沟通FOB发货；提货款催收中；包装运输推进中。批注提示电控/非标设计严重逾期、钢结构生产逾期；存在发货款风险。

阿联酋开心果和杏仁筒仓项目（高风险）
中东战争影响接货；已发函催付货款并确认发货日期；提货款沟通催收中，包装运输推进中；客户接收货风险仍在。

菲律宾Davao及Cebu淀粉仓项目（高风险）
设计、制造均为中度逾期；达沃预付20%已收，0720踏勘后又有变更；施工合同与变更确认待签；绞龙供期至10月、品牌电机0903；业主反复事务多，执行困难、风险大。第1批次货物0629已发运。

蒙古新2×7000T水泥仓系统项目（中风险）
土建计划0831完工，钢构/设备施工约35%、发货约75%；整体收款约35.8%（0729），业务需催进度款；存在供货与施工进度款支付风险。

埃及2×500t水泥仓项目（中风险）
制造中度逾期、进度约95%；钢构设计/业主确认延迟约3个月，计划0818交货验货；发货、验货与货款沟通中；中东局势下业主接货存在风险。

埃及2×1万吨水泥仓及输送项目（中风险）
施工验收中度逾期；筒仓施工已交接完成，设备指导安装进行中；指导施工时间过长。

阿尔及利亚颗粒仓和储罐项目（中风险）
制造基本完成（黄灯）；设计保温有延误；暂定供货截止0825。

埃及8×9000吨水泥卷边仓项目（中风险）
筒仓指导安装已完成；设备指导安装待信息和再次进场安排；安装完工验收款等回款节点仍需盯控。

乌兹别克碳酸钙筒仓项目（中风险）
已验收，备品备件发货及增补雨棚（漏水）执行中；存在5%质保扣款风险。
