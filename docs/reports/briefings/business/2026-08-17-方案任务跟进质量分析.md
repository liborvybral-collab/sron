**数据**：业务部累计创建方案任务，2026-01-01 至 2026-08-17，169 条。填报版本为 0821「崔经理暂未更新版」。

## 一、先看结论

169 条方案任务里，**能确认签约的只有 1 条**（陈子凡 / MAK 2×150 吨）。去掉崔阳未填的 38 条，剩下 131 条可评估：

| 口径 | 数量 | 占可评估 |
|------|-----:|--------:|
| 有效项目（签约 1 + 有效在手 24） | 25 | **19%** |
| 规范闭环（该关已关） | 59 | 45% |
| 前期调研（规划 / 只要预算 / 了解价格 / 找钱） | 17 条 / **16 个客户** | 13% |
| 浅层等待（已报价后被动等） | 12 | 9% |
| 该结未结 + 重复开单 | 13 + 5 | 14% |

进行中挂着 70 条，看起来盘子很大；把前期调研、该关不关、重复拆单拿掉之后，**真正还在推进的只有约 24 条**。这就是「提报很多、有效项目不足」在台账上的样子。

三种不同的病，不要混着批：

1. **入口太松**：只要预算、中间商探价、澄清还没回就进管家。代表：陈辉前期调研 7 条、司斌预算类、马鹏飞 3 条澄清未回后失联。  
2. **该关不关**：无反馈、希望不大、可上可不上仍标「进行中」。代表：司斌 5 条该结未结 + 咖啡客户拆 3 条；冯乐 6 条全部进行中、一条没关。  
3. **台账空白**：崔阳 38 条（22 个客户）进展和状态全空，重点项目「75 万吨小麦深加工」同样空白，**无法评估跟进质量**。

## 二、口径（怎么数）

| 维度 | 怎么算 |
|------|--------|
| 提报任务总数 | 管家创建的方案任务条数；同一客户多条分别计 |
| 已结项或暂停 | 已结项-签约 / 已结项-丢单 / 已结项 / 暂停 / 项目暂停 |
| 前期调研 | 进展写明规划、只要预算、了解价格、收集报价、找钱、非最终业主探价，尚未进入实质商务 |
| 前期调研客户数 | 按客户编码去重；无编码按标题 |
| 重点项目 | 标题标注「重点项目」，另按业务确认补录 2 条（菲律宾生力取料机、MAK 2×150 吨小仓），共 16 条 |
| 有效在手 | 进行中，且有真实互动或下一步（拜访、更新方案、授标、征地、约见面、技术澄清），排除纯预算和该结未结 |
| 该结未结 | 失联 / 无反馈 / 希望不大 / 可上可不上，仍挂进行中 |
| 有效项目率 | （签约 + 有效在手）÷ 提报总数。衡量「提了之后还剩多少真项目」 |
| 闭环率 | 已结项或暂停 ÷ 提报总数。衡量敢不敢关账，**不代表能成交** |

崔阳 38 条不参与有效项目率对比。冯乐、郭朝伟、张硕、王伟超样本量小于 8，百分比波动大，只作参考。

## 八、丢单在说什么

可评估样本中，有原因记录的丢单/关闭以 **客户失联 19 + 客户未反馈 3** 为第一因，其次价格 8、需求不实 2、选其他供应商/混凝土仓 2。

## 九、建议（对着「无配额」这件事）

不设数量配额可以保留，但必须补三道闸，否则提报量会继续代替有效项目。

1. **入口**：只要预算、非最终业主探价、澄清未回，进管家时强制标「前期 / 探价」，不进月度在手项目。同一客户默认一条任务，版本升级改原任务，不新开。  
2. **退出**：进行中超过 60 天仍停在「已报价、等回复、无反馈」，自动改暂停或丢单；「希望不大 / 可上可不上 / 战争前不可能上」当场结项。
