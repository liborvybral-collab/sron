2026年8月6日至7日，《2026年中经营分析会》第二阶段重大议题讨论会在公司培训室举行。会议围绕**产品定位、市场营销、公司经营、核心竞争力打造及其他议题**五个方向，组织公司管理层建言献策、充分讨论，形成一系列重要共识，为下半年经营策略和重点工作明确了方向。相关纪要如下：

> **会议核心共识（速览）**
>
> | 方向 | 核心结论 |
> |------|----------|
> | 产品 | 聚焦四大散料整体解决方案；减重约20%为生死任务；智能化方案须标准化输出 |
> | 市场 | 品牌全员共建；8月底前完成专业素材包；同步建案例库与成本数据库 |
> | 经营 | 计划运营任“总导演”并赋考核权；5000万以上大项目推行双轨制；强化补位文化 |
> | 竞争力 | 对标丰尚补短板；加快自有工厂与一级资质；能力须下沉、审核须从严 |
> | 其他 | 考勤与出差调休政策总体维持现状 |

# 一、会议纪要

## 第一部分：产品定位

> 本部分共识：**做什么**——四大领域整体解决方案；**怎么赢**——减重攻坚+智能化标准化；**往哪走**——第二增长曲线+自有工厂。

### （一）明确四大领域产品边界，打造公司产品能力圈

1、**产品定位**：公司核心产品为**大宗散料存储与转运工业系统**。持续迭代对“统仓”产品的理解，坚持提供整体解决方案，不做单一设备销售。

2、**能力圈边界**：按粮食、建材、矿产、煤炭四大类大宗散料，重构产品体系：

| 领域 | 主要覆盖范围 |
|------|--------------|
| 粮食 | 储备库、码头装卸、仓储转运烘干综合体、M&E机电、粮油饲料厂仓储、生物质颗粒、特种物料（咖啡豆/开心果/杏仁）、种子仓、面粉气力输送、平房仓等 |
| 建材 | 散装码头、水泥厂原料及成品仓储、特种水泥动态计量、封闭料场、矿渣微粉发运、辅料配料输送、水泥厂改造等 |
| 矿产 | 磷矿火车装车、碳酸钙超细粉装运、矿物码头装卸、封闭堆场、氧化铝储运、10V10存储输送装卸等 |
| 煤炭 | 快速定量装车站、粉煤灰气力输送及发运、封闭堆场、码头装卸船系统等 |

3、**差异化要求**：从客户视角重新定义产品价值，重点回应结构安全、存储安全、防腐防雨、气密性、能耗、价格等痛点；装配仓等优势领域须深耕细作。品牌网站（SR.com）将系统化展示上述产品体系。

### （二）升级使命愿景，统一战略表达口径

1、**使命**：让人类民生基础的大宗散料安全存储和高效流转。

2、**愿景**：成为全球大宗散料储运的国际工业品牌。

3、**经营框架**：企业经营锚定四个维度——产品迭代、市场获客、经营执行、核心竞争力，形成统一战略表达。

### （三）攻坚产品减重，突破结构竞争力短板

1、**问题确认**：当前产品结构重量较竞品（风尚/丰尚）约重**20%**，已直接削弱市场竞争力，须作为生死攸关的专项任务推进。

2、**四条减重路径**：

| 序号 | 路径 | 要点 |
|------|------|------|
| 1 | 高强材料 | 采用屈服强度450等高强钢，兼顾降重与降本 |
| 2 | 标准研究 | 对标欧标、美标，寻找相对国标的合规减重空间 |
| 3 | 实验验证 | 获取关键参数一手数据，支撑精准设计 |
| 4 | 建模优化 | 优化支撑、栈桥、连接板等细节，避免简化建模造成浪费 |

3、**设计规范统一**：
- 计算口径：按**有效仓容**，而非总容积；
- 密度取值：结构核算取更稳妥的更高值，报价结合有效容积与压实率说明；
- 承诺方式：装料能力建议改为按**立方米**承诺，规避容重波动带来的交付风险。

4、**机制保障**：公司支持工程师突破国标框架开展创新设计，不因非标设计简单追责；同步推进标准产品体系与公司级技术规范，支撑工厂产线与快速响应。

### （四）推进智能化方案标准化，提升投标专业度与溢价能力

1、**现状**：硬件配置较全（PLC、连锁保护、测温等），软件可输出实时数据；但AI应用尚不成熟，投标智能化描述缺少统一模板，价值难以被客户感知。

2、**要求**：制作PPT形式的智能化方案说明模板，清晰展示软硬件配置、功能亮点及客户价值；各业务部门提案须详述自控系统构成与优势，不得一句话带过。

### （五）布局第二增长曲线，延伸主业价值空间

1、**基本判断**：须在主赛道趋缓前布局第二曲线。国内建材行业已进入下行通道，智能化、无人化、小袋包装自动化等为主要增量方向。

2、**业务延伸**（与主业协同）：

| 方向 | 内容 |
|------|------|
| 前端 | 项目前期规划设计咨询 |
| 后端 | 海外项目代建与运营管理 |
| 客户深挖 | 老客户中国区采购代理、销售总代理 |
| 贸易拓展 | 镍矿、咖啡豆等大宗贸易 |
| 新物料 | 化肥、新能源材料等存储需求 |
| 低碳机遇 | 东南亚碳交易背景下生物质燃料存储 |

3、**技术融合**（优先推进）：光伏储能+统仓（适用高电价市场，如菲律宾）；地下粮仓（对标日本低温仓）；保温仓（保障储运品质）。上述方向与主业系统能力结合，避免另起炉灶。

### （六）推进工厂建设规划，夯实交付与信任基础

1、**战略定位**：工厂建设是战略关键节点，涵盖选址、产线、功能分区与经济测算。

2、**功能分区**：客户接待与品牌展示｜核心产品制造加工｜研发基地｜质检、物流、仓储中转及再包装。

3、**选址策略**：
- 规模：约2万平方米（约30亩）；
- 区位：郑州周边车程1小时内；
- 方式：现阶段优先租赁，同步关注法拍厂房/土地（阿里、京东拍卖等平台）；
- 跟进：刘辉、秋阳负责调研，为决策提供可选方案。

## 第二部分：市场营销

> 本部分共识：品牌不是品牌部一家的事；**案例+素材+成本数据**是打单三件宝。

### （一）重构品牌宣传与协同机制，推动全员品宣

1、**新媒体问题与对策**：抖音等平台对未付费账号存在消息屏蔽，导致询盘流失。须尽快对接官方接口解决，并推进付费工具接入，保障沟通链路畅通。

2、**协同机制**：
- 各部门强化“全员品宣”，主动提供项目亮点、技术突破、典型案例等素材；
- 品牌部定期参加各部门例会（每次约10–15分钟），系统收集宣传节点；
- 一人管理二十余个平台的人力瓶颈，须通过跨部门协同缓解。

3、**品牌目标**：
- **对外**：围绕四大核心产品及差异化能力（绿色智能EPC、光伏结合、地下粮仓、保温仓等）创造商机；
- **对内**：通过内部新闻、活动报道增强凝聚力；
- **抓手**：以标杆项目案例为核心载体，对标布勒、怡宝、哈沃等头部企业做法。

4、**素材标准化**（节点：**8月底前**）：
- 工艺、结构、土建、电气、质检、工程管理等条线，完成本领域PPT沉淀；
- 分粮食、工业两个方向，形成可对外宣讲的标准素材包；
- 建立现场拍摄培训课程，纳入新人培训，形成知识资产。

### （二）提高打单成功率，强化标准产品、技术协同与报价闭环

1、**产品与资源聚焦**：
- 推出3000吨、5000吨等“准标品”，引导需求模糊客户，优化价格与交期；
- 总经办与业务管理部门牵头项目分级，重点项目集中技术、商务与时间资源。

2、**技术协同要点**：
- 推进方案设计标准化，减少重复劳动；
- 从客户痛点提炼“设计思想与亮点”，为业务提供差异化弹药；
- 方案阶段统筹装配化、镀锌等精品要素，提升专业形象。

3、**报价文件升级**：完善设备选型、配置参数、安装细节、照片及工艺流程；建立常用设备型号库；投标阶段钉死关键细节，避免现场争议。

4、**数据闭环**：总经办清单化跟踪“方案设计任务”，记录中标/丢标原因及竞对信息，反哺技术与业务改进。

5、**成本支撑**：建立公司级“成本数据库”；探索业财融合软件，打通物资、采购、财务；研究“成本价+利润空间”报价模式。

### （三）建设项目案例库，促进知识共享与经验复用

1、**案例库建设**（品牌部牵头）：
- 常规项目：1–3页概要（规模、仓型、设备、功能、交付时间、非保密业主信息）；
- 标杆项目：独立PPT（如物资联份、越南咖啡豆等）；
- 用途：网站、宣传册、打单支持的统一信息源，须动态更新。

2、**复盘机制**：项目中标或执行结束后，组织业务、技术、工程开展面对面复盘，补充案例库，沉淀可复制经验。

## 第三部分：公司经营

> 本部分共识：**效率是内功**；计划运营要有权推动；大项目要有专班；协同靠补位不靠推诿。

### （一）提升项目执行效率，优化计划运营职能定位

1、**主要痛点**：

| 类别 | 具体表现 |
|------|----------|
| 目标认知 | 对项目整体目标理解不统一 |
| 职责协同 | 边界模糊，主动协同不足 |
| 流程机制 | 会议冗余；流程多但不可操作，易成推诿借口 |
| 信息交付 | 状态不同步，交付结果意识偏弱 |

2、**改进措施**：
- 本职优先 + 主动补位；
- 分批设计/采购，轻重缓急排序，长周期工作优先；
- 非关键环节适度容错，不确定事项可后置处理；
- 双周例会 + 钉钉跟踪 + 绩效考核，实现预警与结项闭环；
- 反对所有事务经计划运营部中转、借机推责。

3、**计划运营定位**：扮演“总导演”，统筹全局、不包办一切；须赋予相应**考核权限**，预警结果纳入项目奖金评定，并在绩效系统升级中落地；强调部门横向沟通，避免协调压力过度集中。

### （二）重构大项目管理机制，推行双轨制攻坚

1、**适用范围**：合同额**5000万元以上**重大项目。

2、**双轨制模式**：“特别小组 + 大项目经理”。大项目经理须具备商务、技术、执行统筹能力，可由业务、技术或工程负责人担任，必要时高管挂帅。

3、**专班机制**：重大复杂项目组建5–7人特别小组，直对高层汇报，赋予资源调配权与考核权，集中优势资源攻坚。

4、**招标流程优化**：

| 阶段 | 牵头部门 |
|------|----------|
| 招标文件起草 | 工程部 |
| 供应商筛选 | 各部门推荐 |
| 招标组织 | 成本合约部 |
| 评标定标 | 工程、计划、成本、技术联合评审 |

可探索“优质采”等电子化招标，注意法律风险。计划运营人力有限，须避免陷入纯事务性工作。

### （三）强化跨部门协同与责任担当，倡导补位文化

1、**现状问题**：“各扫门前雪”、相互指责、缺整体格局；业务前端压力过大，难兼顾开拓与执行。

2、**文化要求**：管理层须有全局视野，主动跨部门协调；倡导“门与门之间的雪谁来扫”的补位文化；未来股权规划向有担当者倾斜。

3、**前后端衔接**：业务拿单后后台接住交付；前端保持业主沟通窗口；避免销售长期陷执行导致新项目断层；重大项目由特别小组承接。

### （四）加强风险管控与效益提升，坚持安全质量底线

1、**事前防控**：加强图纸会审与技术交底；建立历史问题案例库；业务端及时反馈业主动态。

2、**变更创效**：业主变更须提出费用补偿；签证事项“算总账”集中处理，避免频繁让步。

3、**安全底线**：海外安全风险严峻，工程例会常态化强调安全；为出差及外派人员购买长期商业保险。

4、**报价并行**：业务主导报价、采购提供数据；方案、清单、结构计算、询价同步推进；业务人员提升基础工艺图能力。

5、**内外平衡**：成本合约部牵头优化合同条款，纠正“内紧外松”，兼顾供应商进度压力与尾款/合作关系。

### （五）搭建可执行的标准化流程，服务打单与交付两条主线

1、**原则**：流程重在可执行，不为堆砌制度，不为推诿借口。

2、**建设重点**：

| 对外统一 | 对内固化 |
|----------|----------|
| 智能化方案模板 | 项目责任人与状态同步 |
| 专业宣传素材包 | 方案设计任务跟踪 |
| 项目案例库 | 成本数据库 |
| 报价文件模板 | 招标分段职责、考核数字化、准标品体系 |

3、**主线对齐**：标准化优先服务“提高打单成功率”和“提升项目执行效率”，与大项目双轨制、计划运营授权改革一体推进。

## 第四部分：核心竞争力打造

> 本部分共识：短板要正视、对标要深入、能力要下沉、工厂和资质要加快补齐。

### （一）正视短板，开展对标诊断

1、**当前主要短板**：

| 维度 | 问题 |
|------|------|
| 产能信任 | 无自有生产线 |
| 资质门槛 | 机电总承包一级资质未突破 |
| 方案专业度 | 呈现缺细节，与头部企业有差距 |
| 质量稳定性 | 如水泥板结等问题影响复购 |
| 审核机制 | 流于形式，低级错误时有发生 |

2、**对标丰尚**：方案更系统、设备描述更详尽、结构重量控制更优。须组织技术人员剖析竞品图纸，技术主管亲自把关审核，杜绝低级失误。

### （二）明确能力建设方向，把技术优势转化为客户价值

1、**能力构建**：加快专利体系（设计—加工—施工全链条）；推进高强钢、钢绞线等新材料研究；推动专业能力下沉，避免知识过度集中。

2、**战略补齐**：加快自有工厂建设（力争年内完成选址与方案设计）；持续推进机电总承包一级资质申报。

3、**本期抓手汇总**：减重技术壁垒｜智能化与方案专业化表达｜案例与品牌资产｜成本数据库与精准报价｜大项目交付体系｜自有工厂与第二增长曲线｜资质与审核机制补强。

## 第五部分：其他议题

### （一）考勤、调休及相关制度安排

1、**考勤**（维持现状为主）：
- 继续钉钉WiFi打卡，基本工时8:30–18:00不变；
- 每月豁免2次10分钟内迟到、3次忘打卡补卡；
- 可研究约5分钟缓冲期；刷脸/自研APP暂不推进。

2、**出差调休**（维持现状）：
- 出差超过7天，每7天折算1天调休，不区分是否含周末；
- 出差薪酬与补贴已按全天候工作性质发放，暂不按双休日额外双倍调休；
- 倡导奋斗文化，调休侧重事务性平衡，建议在项目间隙合理使用积假。

3、**综合结论**：考勤与出差调休政策总体维持现状，结合项目节奏做好弹性安排。
