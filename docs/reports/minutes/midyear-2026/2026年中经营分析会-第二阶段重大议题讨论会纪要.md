# 2026年中经营分析会·第二阶段重大议题讨论会纪要

**会议主题**：重大议题讨论（产品定位、市场营销、公司经营、核心竞争力、其他议题）  
**会议阶段**：年中经营分析会 · 第二阶段工作  
**纪要口径**：按议题归纳讨论要点、已形成决策/共识、责任事项与节点要求（参照管理层周例会纪要写法）

## 开篇综述

本次重大议题讨论围绕五项议题展开：产品定位与第二增长曲线、市场营销与打单、项目执行与跨部门协同、核心竞争力打造、考勤/调休制度。会议形成的主线共识为：

1. **产品侧**：以粮食、建材、矿产品、煤炭四大散料领域系统化服务为定位边界；把产品减重约20%作为生死级攻坚任务；同步布局光伏+筒仓、地下仓等第二增长曲线，并推进自有工厂选址建设。
2. **市场侧**：品牌建设全员负责；以标杆案例为主要宣传载体；8月底前完成对外宣传标准物料包；同步启动案例库与成本数据库建设，提升打单成功率与报价精度。
3. **经营侧**：效率是业务升级的关键；落地大项目双轨制（专班+项目经理），赋予计划运营部实质协调与考核权，强化补位文化与风险前置。
4. **制度侧**：考勤/调休维持现状，坚持奋斗者文化，周末出差不以双倍调休计，按全天工作补贴/工资处理。

## 一、产品定位

### 1. 公司核心产品是什么？怎么做好产品差异化？

**讨论要点**
- 产品定位向**粮食、建材、矿产品、煤炭**四大领域系统化服务收敛，明确散料四大品类系统服务边界。
  - **粮食**：仓房、码头卸船、气力输送等系统。
  - **建材**：散装装车头、水泥筒仓储、改造类项目。
  - **矿产/煤炭**：封闭料场、快速定量装车站等。
- 使命与愿景升级方向：
  - **使命**：让关乎人类基本民生的散状物料高质量储存与高效流转更安全。
  - **愿景**：成为散状物料储运领域全球性国际工业品牌。
- 差异化路径：以品牌影响力与订单获取强化市场地位；以技术壁垒形成客户依赖；智能化方案对外表达必须标准化（硬件/软件配置、功能亮点、客户价值），提升投标专业度与溢价能力。
- **核心痛点（已确认）**：当前产品重量相较竞争对手（如丰尚等）约重**20%**，直接影响竞争力。

**形成共识 / 已决策**
- 产品减重约20%列为专项攻坚，成立专班推进。
- 技术路线：采用高屈服强度450钢材降重降本；研究欧标、美标等国际标准中的减重空间；强调“有效仓容”而非笼统容积，统一密度标准；装机能力承诺由吨位表述转向立方米表述，降低履约风险。
- 智能化方案须形成统一对外PPT模板，并在下次会议前完成。
- 总工程师牵头，通过创新设计突破偏僵化的国标框架约束，构建“技术护城河”。

**行动事项**
| 事项 | 责任方向 | 节点/要求 |
|------|----------|-----------|
| 产品减重专项攻坚（目标约20%） | 技术总工牵头，成立专班 | 作为核心竞争力生死任务持续推进 |
| 智能化方案标准化PPT模板 | 技术/方案相关责任人 | 下次会议前完成 |
| 四大领域系统服务边界与对外表达统一 | 业务+技术+品牌协同 | 与宣传物料包一并落地 |

### 2. 第二增长曲线应该是什么？

**讨论要点**
- **业务延伸**
  - 前端：咨询与项目策划服务。
  - 后端：海外项目技术与运营管理输出。
  - 国内既有客户场景探索采购代理/销售代理角色。
  - 依托资源探索矿产、咖啡豆等大宗贸易协同可能。
- **技术创新与融合**
  - **光伏+筒仓**：仓顶/仓壁布置光伏，优先面向电价较高市场（如菲律宾）。
  - **地下仓**：研究日本低温仓等技术路线，服务粮食品质。
  - **保温/控温技术**：围绕储存与转运过程中的品质稳定。

**形成共识**
- 第二增长曲线优先加速布局：**光伏储能/光伏+筒仓**与**地下仓**方向；与主业系统化服务能力形成组合，而非另起炉灶。

### 3. 工厂建设的建言献策

**讨论要点**
- 初步构想：建筑面积约**2万㎡**，选址郑州周边约**1小时交通圈**内。
- 功能分区：展厅接待、生产、研发、物流仓储。
- 策略建议：优先租赁或购置法拍/低成本厂房，控制初期投入；由专人团队（刘辉、孙阳）调研低成本标的。
- 与核心竞争力议题联动：加快自有工厂建设与资源整合，支撑产品差异化与交付能力。

**形成共识 / 已决策**
- 工厂建设列为战略任务，选址调研与低成本拿厂路径同步推进；与年内能力建设目标对齐，加快落地节奏。

**行动事项**
| 事项 | 责任方向 | 节点/要求 |
|------|----------|-----------|
| 低成本厂房/地块调研（租/购/法拍） | 刘辉、孙阳等专项人员 | 持续推进，尽快形成可选方案 |
| 工厂分区与产能匹配论证 | 计划运营+相关业务/制造条线 | 与交付能力议题一并论证 |

## 二、市场营销

### 1. 如何更好做好品牌宣传？

**讨论要点**
- 新媒体运营存在技术/机制问题（如抖音屏蔽导致信息漏接），需专项解决。
- 强化**全员品牌**意识：其他部门应主动向品牌侧输送“弹药”（项目亮点、现场素材）；品牌部门参加各部门例会收集素材。
- 业务机会聚焦核心产品（粮食、建材等）与差异化能力；宣传主载体对标利乐、布勒等，以**标杆项目案例**为主。
- 推动现场拍摄培训，把一线作业转化为可复用的公司知识资产。

**形成共识 / 已决策**
- 品牌建设是全公司责任，不是单一部门职责。
- **8月底前**，各部门完成对外宣传标准“物料包”（PPT等）。
- 由品牌部门牵头建设统一**项目案例库**：一般项目1–3页摘要，重点项目形成专项PPT，用于官网、画册、销售打单；项目完成后组织跨部门复盘，沉淀可复制经验。

**行动事项**
| 事项 | 责任方向 | 节点/要求 |
|------|----------|-----------|
| 各部门对外宣传标准物料包 | 各部门，品牌统筹 | **8月底前完成** |
| 项目案例库建设 | 品牌部门牵头 | 立即启动 |
| 品牌参加部门例会收集素材 + 现场拍摄培训 | 品牌+各部门 | 机制化常态推进 |
| 抖音等新媒体技术问题排查 | 品牌/信息化相关 | 尽快闭环，避免线索漏接 |

### 2. 怎么提高打单成功率？

**讨论要点**
- **产品分级与技术协同**：针对需求不清晰客户，推出“标准产品”（如3000吨、5000吨档）优化价格与交期；总经理牵头产品分级，资源向高优先级项目倾斜；技术人员要从客户痛点中提炼设计思想与亮点，避免纯重复劳动。
- **报价机制与数据闭环**：基于历史数据建立公司级**成本数据库**，保障精准报价；探索财务、采购、材料联动的动态成本分析工具；建立方案设计任务跟踪机制，分析中标/丢标原因，形成数据驱动改进闭环。

**形成共识**
- 立即启动**案例库**与**成本数据库**建设。
- 以标准化物料 + 精准数据化报价提升市场竞争力与打单成功率。

**行动事项**
| 事项 | 责任方向 | 节点/要求 |
|------|----------|-----------|
| 产品分级（含标准产品包） | 总经理牵头，业务+技术协同 | 尽快落地分级规则与资源倾斜机制 |
| 成本数据库建设 | 成本合约/财务/采购协同 | 立即启动 |
| 方案设计任务跟踪与中标/丢标复盘 | 业务+技术+计划运营 | 形成闭环机制 |

## 三、公司经营

### 1. 怎么提升项目执行效率？

**讨论要点（执行痛点）**
- 项目缺少统一“负责人”，管理碎片化。
- 跟踪参与不全，项目状态不同步。
- 流程不清，部门间事前告知与协同不足。
- 交付结果意识弱，信息传递滞后。
- 底线要求：标准化作业流程，强化信息传递，以效率为目标。

**计划运营部职能定位**
- 定位为公司级“总指挥/参谋部”，需具备全局视角。
- 应赋予对各业务/执行部门的**实质考核权**。
- 主动打通部门缝隙、前置识别问题，减少内耗与推诿。

**形成共识 / 已决策**
- 授予计划运营部公司级协调与考核授权，打破部门墙，构建效率导向的交付体系。
- 在满足外部客户需求与内部资源约束之间做好平衡。

### 2. 怎么提升大项目协作能力？

**讨论要点**
- **大项目经理制**：对合同额约**5000万以上**项目实行双经理/双轨管理；项目经理需兼具商务、技术与执行综合能力；以专业化管理解决“中标后交不好”问题。
- **专班项目小组**：跨部门专班直接对高层负责；统一目标与考核，对标行业最佳实践，提升决策效率。
- **指标体系**：核心绩效层层分解到人；任务与KR/部门目标挂钩；强化跨部门协同与执行效率指标；指标体系数字化，避免信息滞后。

**形成共识 / 已决策**
- 落地**大项目双轨制**：专班 + 项目经理，明确领导责任与资源优先保障，全过程跟踪确保执行。

### 3. 怎么做好跨部门协同？

**讨论要点**
- **补位文化与责任担当**：打破部门墙，主动补位；提倡主动汇报与ownership，反对被动等待；业务部门应牵头交付而非甩锅；跨职能事项明确主责/次责，避免边界卡死。
- **风险管控与效益提升**：从事后补救转向事前预防；建设项目风险库；以回款与现金流为绩效杠杆；减少流程冗余，提升利润空间。
- **安全保密与成本控制**：对外安全风险零容忍；强化项目信息保密意识；严控成本预算与审计；坚持“质量是生命”。

**形成共识**
- 边界事项必须清晰主责；风险前置、回款牵引、质量与安全守底线。

### 4. 公司标准化流程应该怎么搭建？

**讨论要点与方向（结合产品/市场/执行议题）**
- 对外：智能化方案标准化模板、宣传物料包、案例库统一口径。
- 对内：项目执行流程标准化（负责人、状态同步、事前协同）；方案设计任务跟踪；成本数据库支撑报价与采购；指标与考核数字化。
- 能力建设：技术解决方案模板标准化；全链条服务能力（研发—市场—交付）拉通。

**形成共识**
- 标准化不是做文档堆砌，而是服务“打单成功率 + 项目执行效率”两条主线；优先落地模板、案例库、成本库、大项目双轨与计划运营授权。

**行动事项（经营条线汇总）**
| 事项 | 责任方向 | 节点/要求 |
|------|----------|-----------|
| 大项目双轨制（专班+项目经理）机制落地 | 公司管理层 + 计划运营 | 明确适用范围（约5000万以上）与权责 |
| 计划运营部考核权与协调机制落地 | 公司授权，计划运营执行 | 尽快发文/例会固化 |
| 项目执行流程与状态同步机制 | 计划运营牵头，各部门配合 | 纳入标准化流程搭建 |
| 项目风险库建设 | 计划运营+项目执行条线 | 从“事后”切到“事前” |
| 技术方案模板标准化 | 技术部 | 与智能化方案PPT同步 |

## 四、核心竞争力打造

### 1. 如何塑造公司核心竞争力？

**当前短板（对标诊断）**
- 客户痛点洞察不足，方案同质化。
- 技术积累偏弱，需聚焦核心技术。
- 决策响应偏慢。
- 产品差异化不足，易陷入价格战。

**能力建设方向**
- 打造从研发到市场拓展的全链条服务能力。
- 建设复合型高能级人才队伍，应对复杂市场。
- 以技术创新与数字化工具提升整体效率。
- 把技术优势转化为客户可感知价值。

**与本期议题的绑定结论**
- 核心竞争力近期抓手清晰：**减重技术壁垒（约20%）+ 智能化方案标准化 + 标杆案例与品牌资产 + 成本数据库与精准报价 + 大项目交付体系 + 自有工厂与第二增长曲线（光伏仓/地下仓）**。
- 已决策强调：突破国标僵化约束、构建技术护城河；加速自有工厂建设与资源整合，形成核心产品差异化。

## 七、会议总结

1. **产品**：四大散料系统化服务定位清晰；减重约20%是必须打赢的仗；智能化方案表达与技术标准创新同步推进。  
2. **增长**：光伏+筒仓、地下仓作为第二增长曲线优先加速；工厂建设与交付能力建设同步布局。  
3. **市场**：品牌全员共建；8月底物料包、案例库、成本库三件事立刻抓；用标准化与数据化抬高打单成功率。  
4. **经营**：效率是升级关键；大项目双轨制 + 计划运营授权是抓手；补位文化、风险前置、质量安全底线不可退。  
5. **制度**：考勤调休维持现状，倡导奋斗者文化与项目周期内的灵活休假安排。
