# 业务部周例会纪要

业务部周例会是国际/国内业务条线的定期经营会议。纪要结构对齐往期管理层例会成稿：会议信息、**工作分享及工作要求**、重点工作与待办。

工作分享按「第×部分：做法，目的」立标题，便于宣贯和对照执行。
