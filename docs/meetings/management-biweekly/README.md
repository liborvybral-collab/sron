# 管理层双周会纪要

管理层双周会议是公司的核心经营会议，每期会上进行经营汇报（PPT）。

## 目录结构

```
management-biweekly/
└── YYYY/
    └── YYYY-MM-DD-第N期.md
```

## 关联文件

- 经营汇报文稿：`docs/presentations/management-biweekly/YYYY/`
- 三个部门月报：`docs/reports/monthly/`

## 请先上传历史纪要

请在此目录下上传 2-3 期历史纪要作为风格参照，例如：

```
2026/
├── 2026-05-15-第10期.md
└── 2026-06-01-第11期.md
```
