## 使用说明

整理会议纪要时：
1. 提供本次会议录音转写文本
2. AI 读取同类型历史纪要学习语言风格
3. 生成后先确认，再保存到对应目录

**请先上传 2-3 期各类型历史纪要，作为风格参照。**
