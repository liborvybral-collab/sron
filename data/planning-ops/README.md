# 计划运营部原始数据

存放计划运营部项目执行月报等原始经营数据。

## 目录约定

```
planning-ops/
└── YYYY-MM/
    ├── README.md
    ├── *.xlsx
    └── *.md
```

对应成稿月报：`docs/reports/monthly/planning-ops/YYYY-MM-计划运营部月报.md`

现场项目周报按月归档，例如：

- `2026-07/pakistan-monthly/`：巴基斯坦SECMC 7月施工月度报表
- `2026-07/mongolia-monthly/`：蒙古MAK2×7000T 7月施工月度报表
- `2026-08/`：8/17–8/23 现场施工周报（巴基斯坦、蒙古，含例会【进度】【成本】口径）
