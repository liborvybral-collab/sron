# 国际业务部月报数据

国际业务部月报 Excel 含多个工作表，按 **一表一 CSV** 导出，存入对应月份目录。

## 月度目录结构

```
intl-biz/
└── YYYY-MM/
    ├── README.md                        # 本月数据说明（从 _template 复制）
    ├── 汇总表.csv
    ├── 1组-陈子凡.csv
    ├── 2组-司斌.csv
    ├── 3组-王伟乐.csv
    ├── 5组-陈辉.csv
    ├── 6组-韩鸿彪.csv
    ├── 俄语组-崔阳.csv
    ├── 明细表1-业务完成指标.csv
    ├── 明细表2-新增客户数量.csv
    ├── 明细表3-销售成本指标.csv
    ├── 明细表4-回款进度指标.csv
    └── 2026-06-国际业务部月报.xlsx      # 原件（可选）
```

## 工作表与 CSV 对应关系

| Excel 工作表 | 导出文件名 | 用途 |
|-------------|-----------|------|
| 汇总表 | `汇总表.csv` | **月报主数据源**，经营概览、核心指标 |
| 1组（陈子凡） | `1组-陈子凡.csv` | 1组业务数据 |
| 2组（司斌） | `2组-司斌.csv` | 2组业务数据 |
| 3组（王伟乐） | `3组-王伟乐.csv` | 3组业务数据 |
| 5组（陈辉） | `5组-陈辉.csv` | 5组业务数据 |
| 6组（韩鸿彪） | `6组-韩鸿彪.csv` | 6组业务数据 |
| 俄语组（崔阳） | `俄语组-崔阳.csv` | 俄语组业务数据 |
| 明细表1-业务完成指标 | `明细表1-业务完成指标.csv` | 各组业务完成明细 |
| 明细表2-新增客户数量 | `明细表2-新增客户数量.csv` | 新增客户统计 |
| 明细表3-销售成本指标 | `明细表3-销售成本指标.csv` | 销售成本分析 |
| 明细表4-回款进度指标 | `明细表4-回款进度指标.csv` | 回款进度分析 |

## 写月报时的数据优先级

| 月报章节 | 主要引用 |
|----------|----------|
| 一、经营概览 | `汇总表.csv` |
| 二、订单与合同 | `汇总表.csv` + 各组 CSV |
| 三、项目交付 | 各组 CSV |
| 四、市场开拓 | `明细表2-新增客户数量.csv` |
| 五、回款与资金 | `明细表4-回款进度指标.csv` + `汇总表.csv` |
| 成本相关分析 | `明细表3-销售成本指标.csv` |
| 各组完成情况 | `明细表1-业务完成指标.csv` + 各组 CSV |

## 导出步骤

1. 打开当月 Excel 月报
2. 逐个切换到上述工作表
3. **文件 → 另存为 → CSV UTF-8（逗号分隔）**
4. 按上表文件名保存到 `intl-biz/YYYY-MM/` 目录
5. 复制 [_template/README.md](_template/README.md) 到当月目录，填写月份信息

## 使用示例

```
根据 @data/intl-biz/2026-06/ 的数据，写 6 月国际业务部月报
```

或指定具体文件：

```
@data/intl-biz/2026-06/汇总表.csv
@data/intl-biz/2026-06/明细表4-回款进度指标.csv
帮我写月报第一节和第五节
```

## 注意事项

- 导出时选择 **CSV UTF-8**，避免中文乱码
- 文件名不要含括号，用 `1组-陈子凡` 而非 `1组（陈子凡）`
- 汇总表和各明细表为写月报的核心，各组表用于分小组分析
- Excel 原件可选保留，便于核对公式和格式
